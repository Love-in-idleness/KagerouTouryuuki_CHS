# KagerouTouryuuki_CHS
霞外籠逗留記的汉化

## 文件说明
gsc文件是游戏实际读取的脚本文件，txt是railiar提取的文件，可通过railiar再合并进入gsc。  
ctx是txt文件的重命名，是与当前汉化脚本用于对比润色的参考翻译。  
exe文件将脚本读取修改为gbk，通过它可以启动汉化后的游戏。   
grpo和grps下是需要汉化的图像文件，本人不太熟悉图像，自己只打算弄掉和选项有关的grpo。至于grps,希望有有缘人能帮忙吧。

## 使用说明
将scr与grpo文件夹与kagerou_gbk.exe放于游戏目录下，启动kagerou_gbk.exe即可。
