# KagerouTouryuuki_CHS
霞外籠逗留記的汉化

## 文件说明
gsc文件是游戏实际读取的脚本文件，txt是railiar提取的文件，可通过railiar再合并进入gsc。  
ini是txt文件的重命名，目的是为了防止脚本合并。（部分gsc脚本由于实际显示问题，已被我直接基于hex编辑修改，无法通过railiar合并）  
exe文件将脚本读取修改为gbk，通过它可以启动汉化后的游戏。

## 使用说明
将scr.mine文件夹与汉化游戏程序本体放于游戏目录下，将并将scr.mine重命名为scr即可。（或者用发行的scr.xfl代替scr文件夹）
