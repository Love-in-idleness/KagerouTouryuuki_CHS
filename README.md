# KagerouTouryuuki_CHS
霞外籠逗留記的汉化

## 文件说明
gsc文件是游戏实际读取的脚本文件，txt是railiar提取的文件，可通过railiar再合并进入gsc。  
10开始是共同线、11开始是小姐线、12开始是司书线、13开始是小姐线、14开始是里线。目前H场景并未润色，请酌情使用。  
exe文件将脚本读取修改为gbk，通过它可以启动汉化后的游戏。   
grpo和grps下是需要汉化的图像文件，本人不太熟悉图像，自己只打算弄掉部分内容。至于其它，希望未来有人能帮忙吧。


### 翻译采用
侍女、小姐（老板娘）、船女（有时称为摆渡人）、筑宫清修（青年）、司书（鬼女）、琵琶法师（平时用法师，有时用琵琶女）  
旅笼、澡堂（有时用浴场）、图书室、小庵、酒馆  
带【】的对话用「」，其余引用使用『』，特殊时（如译者注释）会用“”
使用全角。    
先生（小姐称呼清修时）、客人（侍女称呼清修时）、老爷（船女称呼清修时）  

## 使用说明
将scr与grpo文件夹与kagerou_gbk.exe放于游戏目录下，启动kagerou_gbk.exe即可。

## 汉化进度
scr：共通线、法师线、小姐线已汉化。  
grpo：随scr汉化。  
grps：关于savescrn、scview、cgview已汉化。dt1汉化进度搁置，未来重新考虑。  
kagerou_gbk.exe：游戏名称显示、字体效果显示、场景鉴赏显示、退出提示、覆盖存档提示、读档提示、返回标题提示已汉化。
