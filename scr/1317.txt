# 黑色小人们的跳梁此后仍在继续，不断困扰着客人，不知何时方休。终于，旅笼的管理方——小姐与侍女们——接到的投诉简直如雨点般劈头盖脑而来。
 旅笼自古便流传着各种怪谈，至今遇上它们也不算稀奇。只是那些大多是无伤大雅的怪事，遇上的人过后也只当多了个谈资，客人与怪异之间勉强算是共存。
 而关于这些小人们，无论是旅笼的各种记录还是口传中都不曾有过，受害也相当严重——毕竟被狂疾所囚之人，即便恢复清醒后也筋疲力竭，不得不长期卧床休养。
>
# 事已至此，自然不能坐视不管。小姐与侍女们为了镇抚小人、驱除它们，用尽了种种手段。然而相传下来的追傩仪式、驱魔符咒，其灵验几乎等于零——毕竟连它们究竟因何而涌现都无从知晓。
 旅笼方面也并非束手无策，但所能采取的对策，充其量也就是让客人们换房间，如此消极而已。
>
# 因为——这是受害频发之后才判明的——小人的出现似乎仅限于沿水路一带的房间。离开水路或楼上的房间，则没有客人声称见过它们。
>
# 却说――
 在那些日子里，几乎没有任何席面——无论是游戏室的闲聊，还是在走廊停下脚步的闲话——不将黑色小人的怪异提上话题。而不知为何，有一个人开始被与这怪异并列谈论。
>
# ――琵琶法师――
>
# 她的小庵也沿水路而建，但据说只限于小庵及其周边，未曾听闻有小人出现。
 原本就很少有人造访她，那一带住客稀少、人迹稀疏——尽管如此，那传言却如同爬过石缝的蜈蚣般悄然扩散，又似隐忍潜伏于房梁的毒蜘蛛般阴险地沉潜于人们心中。
 那传言，是关于为何唯独法师的小庵没有出现怪异的。
>
# 传言这东西，照例添油加醋，最终归结为一点：她藏有名香。
>
# 本来，芬芳浓郁的香，被认为能清净、镇静身心。其药效不止于此，据说还秘藏着驱魔避邪、乃至招引魔物的灵验。
 就连隐匿于世的恶魔学之徒，在描绘五芒星魔法阵、执行召唤术时，香料的熏烟也是必不可少的——那既是向魔物的供品，也是护身的结界。
 此外，大陆汉朝武帝难忘已故李夫人的面影，焚返魂香，其姿便现于烟中——有此典故。西行法师隐栖山中时难耐孤独，为使荒野白骨复活为友而行此术时，所用的也是那返魂香。
>
# 虽列举了少许博物学的例证，总之是关于香的灵验。它既非斩魔除邪的利剑，也非威吓驱逐的威严之姿，但切莫小看那只是芬芳之气——多少也算是个佐证。
 再者，香有动物性来源与植物性来源，如此这般……不，不在这里罗列博学宏论了，还是回到以旅笼为舞台的故事流中来――
>
# 总而言之，琵琶法师虽沿水路居住，却能免受黑色小人们的侵害，是因为她暗中藏有灵验无比的名香——这般煞有其事的传闻，不知何时起已挂在人们的嘴边。
>
# 起初，也有人冷静地质疑：那样一个穷困潦倒，值得一提的只有一把又旧又脏的琵琶，吃的东西不过是揪些路边的杂草做菜的女子，怎会拥有那般稀罕之物？
 甚至有人揶揄：那女人除了弹琵琶、缠着人说话之外，既无高迈的智慧也无见识，是个愚昧之人，珍贵之香哪里配她？
>
# 然而，当怪异的危害频繁到不可忽视时，困境模糊了判断力。人们的想法渐渐转变：或许她真的有？不，她一定有。单是这样倒也罢了，甚至带上了责难的意味：既然有那样的驱邪之物，为何只她一人独享恩惠？
>
# 连有没有都不确定的东西，就确信『一定有』——这姑且不论；但因此而疑神疑鬼，认为法师独占了它，这趋势颇有些不自然。虽有质疑之声，终究被大势淹没。
>
# ……但倘若此处有一位研究口碑传承的学徒，能够鸟瞰并分析传言的发展，或许会发现流言的源头，以及人们所忽略的某个事实。
>
# 那个说法师藏有香料的传言——若像追循织物的绫线般仔细追溯其源头，应该会追溯到那个地下酒馆，落在一个用下贱言语与手势说长道短的男人身上。
 那个品行不端的醉汉，那个企图嘲笑、玩弄法师，令筑宫愤慨不已的男人。
 同时，也会查明另有一个客人——同样取了水边的房间，却既不曾见也不曾闻黑色小人们的怪异——被众人忽略了。
 那个客人，正是据说失去过往记忆的年轻男子——是的，筑宫清修本人。
>
