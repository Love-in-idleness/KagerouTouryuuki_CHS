# 途中，或许稍稍弄错了走廊拐弯的顺序，也曾折返过几次，但筑宫终究还是找到了那间疑似目的地的图书室。
 这座旅舍仿佛按区域混杂着各种建筑风格，随着他依照侍女所给地图前行，眼中熟悉的和式格局渐渐掺入了零星洋风的元素。图书室所在的这一隅，并非前近代那种湿气氤氲的纯日式宅邸，倒更像是西洋建筑初传入时所建的官舍或学堂——干燥、清朗，带着某种历史过渡期的暧昧气息。回想起来，打从大河对岸眺望旅舍时，便已觉察东西洋风杂糅一处，与其说是融合料理，不如说更像一锅乱炖。
>
# 他终于寻到了这间屋子——
 门上并无『图书室』之类的标牌，然而筑宫却确信无疑：此地正是图书室。
 久经使用的书架上密密排列着书脊，色彩纷呈，开本各异，宛如一幅由趣味与变幻织就的镶嵌画。
>
# 说来，满载书籍的书架，哪怕只一架，也似为防备知识散佚而备下的方舟，庄重肃穆；若成列成排，则庄重已不足形容，竟至令人肃然仰止。
 市井间有所谓『三一书房』的书肆，其所刊行的小说全集，尽是些名气不大（恕我直言）或风格奇诡的作家之作。
 故而坊间时有戏言：此『三一』非彼『三一』，实乃『散佚书房』之谓也……罢了，此乃题外。(译者注：那个“彼『三一』”指的是一个日本著名的左翼出版社，曾出版了《毛泽东选集》《绝密官方文件与强迫征召慰安妇》等书籍，其在推特（X）上有句推文：“一个不从经验中汲取教训的社会是没有未来的”。)
 总之，此处书架之列，毫无寻常藏书处那般逼仄拘束之感。
>
#【清修】
（……该怎么说呢？总觉得，这样的地方，挺稀奇的……）
>
# 他仿佛向满室静默致以敬意，悄然以手背掩门，不令其发出声响，脚步亦轻如落叶，唯恐惊扰了这份宁寂。他穿行于书架的谷隙之间，目光匆匆掠过书脊。仅此一瞥，书名便如流水般滑入脑海——盖因架上多是小说与故事集，虽皆略显过时，却易识易读。
 当然，亦有满纸汉字、一望即知乃专业著作或研究书者，但小说之疆域终究更为广袤。
 正是这般藏书分布，赋予此图书室一种难得的松弛与亲切。
>
#【清修】
（本以为图书室该是堆满艰深典籍的地方……）
>
# 筑宫随手抽了几册，翻开底页，见多处写着『某某氏寄赠』。他推测，这些书并非某人一次性大量捐赠，而更似多位旅人各自携来数册，零零碎碎，陆续存于此处。
>
# 这里的藏书，或许正讲述着这样一段历史―――
 那些旅人曾在这旅馆投宿，而后又匆匆离去的。临行之际，他们将藏在行囊深处的消遣之物，凭自己的意志留在了这座图书室。这样的猜想，在筑宫的脑海中浮现。
>
# 世上确有一类人，将旧书室中那股无论如何通风也挥之不去的纸香与微霉之气，视作胜过世间任何名香的至福芳华。
 此等人被称作书痴。虽未必真至『痴』之境，筑宫自己却也略染此癖。
 他此刻胸腔中正盈满古纸的气息，微微的快意悄然滋生；而书架间无人的寂静，亦为他带来一份隐秘的欢愉。
 ——就在此时，他的脚步忽然停住，仰头凝视书架最上一排。
>
#【清修】
「……嗯？」
>
# 他并非因失声而僵立，害怕那些潜伏于书隙间的书灵或蠹鱼精怪会因久寂乍闻人语而蹙眉，以指抵唇，嘘声责备。
 他的目光牢牢钉在最上排某册故事书的书脊上，眼神却仿佛穿透了那标题，望向更遥远的彼方，浮着一层恍惚的光晕。
>
# 那书名本身，并非收藏家垂涎的稀世孤本，不过是寻常市立图书馆闭架区也能寻见的普通册子。问题在于——
>
# 筑宫，竟对那书名有印象。
 而他，可是个将自己过往一切记忆，尽数遗落于某处之人。
>
# 在这静得连睫毛轻颤都似有声的刹那，青年缓缓环顾四周，寻得一架合适的脚凳拖来——动作木然，如被无形丝线牵引的傀儡。
 他意识中唯余那本书，其外皆被驱逐；旁人看来，他踏上踏板的姿态，简直如初学步的婴孩妄图攀树般岌岌可危！
>
#【清修】
「我记得的，我认得……！」
>
# 然而，他危颤颤地攀上一级、两级，眼中所见唯有那册书。
 说不定——
 说不定———！
>
# 这本平凡无奇的单行本，或许正是能解开他记忆封印的魔法之书。
>
# 他伸手欲取，似要将遗失的过往亲手牵回。就在此刻——
 登高方觉其险：地板仿佛骤然远去，比实际更低、更遥。他猛然惊觉自己竟立于脚凳之上，顿时慌乱不已。
 若他始终专注书本，或许还能无知无畏，但可惜迟了。
 眼前地板的晃动，其实是他自身姿势的摇晃失衡。
 他猝然失重，双臂如飞鸟扑空般乱舞——旁观者眼中是滑稽的默剧，他自己却在与重力作殊死搏斗，只不过徒劳无功。
 以地球的视角来看，让筑宫的脚底滑离踏板，是那样轻而易举。
 筑宫的视野中，书脊的行列倒流而下。
>
# 倘若筑宫怀揣一枚银口法螺，于地板迫近之际弓身反仰，掠过书架顶板，如鞍马山天狗般直飞仙界，或可免此坠落之怖。
 然而，他当然不可能拥有此等神通。于是，他只能头朝下直坠而落，眼看便是颅骨撞地、余生卧床缝骨的凄惨结局——一卷终章，竟如此狼狈……
>
# 后悔如潮，瞬间漫过心田，却未见走马灯。
 甚至连预想中的痛楚，也未降临。
>
# 有的，只是如层层羽纱叠就的柔软触感。
 飞扬的，并非地板缝隙积尘，而是如彩玻拉丝般柔滑、波光流转的发丝。
>
#【声音】
「危险啊。」
>
# 声音亦如蜜糖浸润，甜入耳底。
 因将坠而生于肌肉之上的紧绷，如冰遇春水，缓缓消融。
 包裹他的并非坠落之恐，而是一种似坠非坠的浮游之感，引得他徐徐掀开眼帘。
 双足仍未触地。
 他被横抱于怀中，姿态如捧易碎奇珍，险境已除，却令他茫然不解：
 到底发生了什么？
 自己为何没有摔下去？
>
#【女子】
「小心些。
 若想取高处的书，
 请唤工作人员一声。好吗？」
>
#【女子】
「应该没事吧？
 有哪里伤着了吗？」
>
# 她俯身凝视他，自肩至背，光泽流转的长发如纱幕般轻柔荡漾。
>
# 然而，真正攫住筑宫心神、令他如修行者遭魔魅摄魂般失语的，并非那丰润秀发，而是她眼镜后那双眸子。
 那双眸，如澄澈琥珀层层叠就，深处时而微漾，时而闪烁，忽又远去，宛如夜之尽头遥遥一点星芒。若说双眸乃心灵之窗，此女心中所藏，该是何等深广？筑宫竟生出面对原始密林、接天绝壁、无垠海原般的渺小与惶然，唇齿间竟吐不出一句应答。
>
#【女子】
「……还好吗？
 莫非撞到哪里了？」
>
# 她再度出声，语中满是人情温意。筑宫眨了两三次眼，那令人窒息的磅礴感便悄然消散，女子复归为一位身量适中的寻常人。
 心绪稍定，他方觉此女虽不张扬，却自有一种图书管理员应有的沉静与娴雅。
 如此规模之图书室，设一司书本属自然不过此刻他又意识到这一身份的另一重职责：若非她，自己早已头破血流。
>
# 然而心头仍悬一疑：纵使他方才心神全系于书，可周围也完全没有旁人的气息；而且，他摔得那样狼狈，这位司书却异常轻巧地接住了他——
 不过，若无她……筑宫不禁再度胆寒。
>
# 筑宫正欲道谢，司书却先开了口。
>
#【司书】
「谢谢你——
 那个，
 你是特意把这本书送回来的吧？」
>
# 本该由自己说出的谢语竟被对方说了去，筑宫一时愕然。
>
# 他正欲致谢，却被对方截了话头。见他一脸困惑，司书以颔示意——正是他先前置于阅览台的那本小说。
 原来他在入室浏览前搁下的书，已被司书敏锐察觉。见筑宫点头，她续道：
>
#【司书】
「最近来这儿的人越来越少啦。
 借出去的书常有不还的。」
>
#【司书】
「——所以，我很高兴。」
>
# 她柔媚一笑，幽香浮动，发丝拂过他胸前。筑宫这才猛然惊觉：自己正被一位美人抱在怀里。
 一瞬之后，薄薄衬衫下传来的体温与丰盈曲线的柔软触感，令这位拘谨的青年大为窘迫。
>
#【清修】
「那个……多谢您接住我。还有……能麻烦您放我下来吗……？」
>
# 他唯恐冒犯对方，却不得不承认：此刻，他其实贪恋这馨香柔软的怀抱。
 然而，筑宫更羞于被情欲驱使，于是在她臂弯中微微挪动——
 当然，动作极尽恭敬。
>
#【司书】
「只要你没受伤，便好。
 ……不过，再这样多待一会儿，如何？」
>
#【清修】
「啊……不，那个……」
>
#【司书】
「……开玩笑的。
 只是觉得，稍稍有些可惜罢了。」
>
# 虽称玩笑，语气中却似藏了一缕真情之焰，筑宫心头再起涟漪。
 忽而，他嗅到她幽香中混入一缕异样气息——
 是旧纸味？不，司书身上有此味不足为奇。但此味更浓烈、更鲜活……莫非是……血的气味？
>
# 未及辨明，司书已不动声色将他放下，随即仰望书架。
>
# 衣料摩挲，窸窣如风。她白衣皓皓，长及小腿的紧身裙褶皱中晕着浅青阴影，看似端庄，寒色布料却紧贴肌肤，反将腰臀曲线勾勒得愈发丰丽。
 双手戴的褐色薄革手套，在室内略显特别。
 虽不及六尺高的筑宫，女子身量在同性中已算高挑。
 衬衫领口与裙腰处的丰腴曲线，恍如男儿梦境凝成实体，妖冶动人。
>
#【司书】
「那么，你想取哪本书？」
>
# 她望着他方才攀爬之处问道。
>
#【清修】
「就是那本……」
>
#【司书】
「嗯……
 啊，那本书……」
>
# 虽狼狈坠落，他岂能就此放弃那本似曾相识之书？
 他与司书并肩而立，指向书架：『从右数第几册……』话音未落，一阵微风拂过他面颊。室内本无风动，莫非有窗悄然开启？他目光不由偏离书架——
>
#【司书】
「给，请拿好。」
>
# 她掌心托书递来。若此刻有纸花绽开或白鸽飞出，筑宫尚可当作魔术一笑置之。
 可这并不是那种玩笑！
 这分明是他欲取之书！
 她竟已取下？何时登梯？他分明未见她动作——那书架顶层，连他踮脚伸臂也难企及！
>
# 无论接人还是取书，单看皆可忍；两事叠加，却透出一丝诡谲。然筑宫不忍以无礼揣度恩人，只得惶恐接过，即刻翻阅，目光疾扫文字。
>
#【清修】
「实在抱歉，给您添麻烦了。」
>
#【司书】
「无妨。
 这也是我的职责。
 哎呀，这本书是……」
>
#【清修】
「嗯？」
>
# 书确有印象，文字亦觉熟悉，情节亦能忆起轮廓。
 然而，仅止于此。他不知何时读过，亦不知是否曾属己有。期盼中的记忆连锁，终究未生。
>
# 或许世事本难如愿。筑宫未显失望，倒显几分成熟；抑或该责其失忆却无危机感？暂且不论。二人同见书名后缀『上卷』二字，皆是一愣——此故事原分上下两册。
>
#【司书】
「只有上卷啊。
 下册在……」
>
# 二人同寻附近书架，却遍觅不得。司书女史轻蹙眉，拳抵下颌。
>
#【司书】
「是借出未还，
 还是遗失了？」
>
#【司书】
「不查借阅簿，怕是难知。」
>
#【司书】
「抱歉，能稍等片刻吗？\t我去查查。」
>
# 筑宫本是闲来逛荡，多留片刻无妨，却觉劳烦对方过意不去。
 何况那书只是因『眼熟』而起意，并非非要重读。
>
#【清修】
「我这边完全不急。若您有其他事，先放一放也无妨。」
>
#【司书】
「没关系。不是说了吗？客人极少。让我帮吧？」
>
# 筑宫闲散，司书亦似久旷。她非但不觉烦，反似觅得解闷良机。筑宫若如此揣度，或有失礼。
 不待他答，她身影已杳，非但脚步轻捷，简直如溶入书影之间。
 他不禁疑心：莫非此女非人，而是图书室感应求书之心，将昔日司书记忆幻化而出？幸而此念未深，一声呼唤将他拉回：
>
#【司书】
「要不要一起喝杯茶？\t干等多无聊。」
>
# 然那声音——远乎？近乎？
 书架林立，声波回荡，难辨方位。似书架自身学她语调，又似自墙角遥遥传来。
 筑宫惶惑四顾，却不见其人。声止，室内静得耳中嗡鸣。
>
#【司书】
「这边，来呀……」
>
# 声自书列彼端传来。他循声回首，终见她立于室隅门前——似是司书室入口。他先前分明细察过那处，并无人影。何时……？
>
# 看来此室罕有访客，司书渴盼交谈。她迎他入内，欣然备茶。
 司书室虽有办公杂物，却散置私物，俨然已成她的闺房。
>
#【司书】
「喝茶可有忌口？」
>
#【清修】
「呃……应无……吧。」
>
# 答得犹豫，因他连自己口味亦已模糊。但既名『茶』，想来不会奉上奇物。
>
# 他落座后不觉紧盯司书动作——只因先前她举止中总有难解之处。
 她似能于瞬息间从近旁移至远处；高处书籍，亦常于他未察时已稳妥取下。此非心神涣散可解，实有异样。
>
# 疑云难抑，筑宫紧盯她一举一动，却也愈发难移目光。
 美人动作本就悦目。她在书车、未理藏书的狭缝中穿行，自生静谧优雅，如香氤氲满室。
 然她娴雅之下，又透出生动魅惑之息，筑宫心跳微促，虽已解衬衫首扣，仍觉领口窒闷。
>
# 细看去，素白衬衫在光线下薄如蜉蝣之翼，肌肤隐约透现；长裙紧裹，反比裸露更显妩媚。
>
# 如此鲜活肉体，绝非幽魂幻影；亦无戏法伎俩。筑宫正欲归因于眼误——
>
#【司书】
「稍等。
 客用茶杯应在……啊，在这儿。」
>
# 她踮脚伸手，欲取头顶橱柜。筑宫忙起身相助，自觉受客礼遇却任其劳作，实在难安——
>
#【司书】
「没事，够得着。」
>
# 她未回头，似背后生眼。然其身量明显不足，亦未寻垫脚之物。接着——
>
# 她以右手握住垂至腕部的左袖，一拧。
 一声如扣具崩裂的脆响，
 随即，
 \t\t\t\t\t\t\t\t滑落———
>
# 筑宫喉间闷哼，悲鸣被牙关生生咬碎。
 此情此景，任谁亦难抑惊骇。
>
# 她左臂自肩肘之间，竟如断刃般分离！
 衬衫空袖失了支撑，凄然飘荡，阴森至极。
>
#【清修】
「那……那是……
 您的手臂……！？」
>
#【司书】
「如你所见——」
>
# 何以她能如草原清风般从容言语？侧脸竟如此泰然？筑宫若非石化，必已瞠目。
 她竟将卸下的左臂，平静举至唇前——
>
#【司书】
「是义手。」
>
# 对比她妖艳如饮血的深红双唇，那义手材质温润，打磨光亮，木纹清晰——一支木制义肢。
 义肢本常与悲惨相连，然配于她优雅侧颜，竟生出一种奇异的典雅之美，虽略带背德意味。
>
#【清修】
「啊……原来如此。不知情下失礼了……」
>
# 衬衫覆袖、手套掩手，外人难辨义肢。
 她坦然展示，反令筑宫自惭方才失态，言语嗫嚅。
>
#【司书】
「何来失礼。
 我用它并无不便。
 你亦如此，不是吗？」
>
#【清修】
「……啊？」
>
# 筑宫下意识检查四肢是否健全。司书续道：
>
#【司书】
「看你神情，似不记往事。
 既无不便，
 那失去之物，便不足为苦——对吗？」
>
# 青年如冰雕凝固。
>
# 初次相见，他未提失忆，她却如透视掌中骰子，一语道破。
 他喉结滚动，吞下唾沫。司书目光并无怜悯或讥讽，只如闲谈中断，静待接续。
 他干唇微润，涩声问：
>
#【清修】
「……您从他人处，听闻过我吗……？」
>
#【司书】
「不曾。
 只是看着你的眼睛，
 不知怎的……就有此感。」
>
#【司书】
「若令你不快，抱歉。」
>
#【清修】
「怎会……只是，竟能看穿至此？」
>
#【司书】
「嘛，或许吧。」
>
# 她未如算命者般长篇大论，只轻描淡写带过，复仰首开柜——
 ……真令筑宫铭心刻骨的，并非她行踪诡秘，非独臂义手，亦非一瞥看穿其失忆。
 而是她使用义手之法。
>
# ——她以卸下之木手，灵巧地拨开高处柜门，取出整套餐具，动作熟稔，稳如常人。
 那义手看似朴素，无精巧机关，竟能如此？
>
# 她以义手代长柄钩取物，如老妪以痒耙勾药盘，虽合理却透出惊人谐趣，令筑宫心情微妙难言。
>
# ………………。
 …………。
 ……。
>
# ……司书所沏之茶，非绿茶亦非红茶，乃传说中大陆某处云巅绝壁岩隙所生异种茶树，一年仅发一芽，需训猴攀摘焙制……云云。她翻着借阅簿闲话此典故，随即笑道：
>
#【司书】
「方才所言，略作戏谑。
 实则不过是日常饮用的铁观音，还是大包装的。」
>
# 她轻巧揭底，又令筑宫莞尔。然其讲述本身已如一篇故事，茶香中巍峨山影浮现，杯中蒸腾雾气恍若润湿岩壁之云。
 茶味精妙，似非啜饮液体，而是吞吐香气精魂，余韵久驻口中。
 或非因美人手沏故味美，筑宫侧目见她翻页——手套已除，肌肤与木手共抚纸页，动作自然得令人疑其亦有血肉神经。
 忽而，她停手：
>
#【司书】
「……似无人借走。」
>
#【司书】
「簿上亦无记录。
 或是夹在哪本书里了……
 暂时难寻。」
>
# 她本无需介怀，然低眉间掠过一丝歉然，筑宫反觉自己强人所难，心生愧疚。
>
#【清修】
「无妨。非急需重读……」
>
#【清修】
「那书只是似曾读过，故而留意。」
>
#【清修】
「本为寻闲书消遣，见之随手欲取罢了。」
>
#【清修】
「不必费心寻找……」
>
# 见他百般宽慰，司书展颜，取桌边几册译文短篇集递来：
>
#【司书】
「那，请收下这些。
 皆为轻松短章，正宜消闲或睡前一读。」
>
#【司书】
「你寻的下册，我会继续找。
 先借这些如何？」
>
#【清修】
「既如此，恭敬不如从命。」
>
# 筑宫本非执着于那套书，又或——
>
# 上下册乃雌雄一体，分离则夜夜悲鸣，搅扰书室清宁，故须成对安放——
>
# 此等古本怪谈，当不存于此。
 他虽觉不必如此热忱，然寻书乃其职责，插手反为无礼。
>
# 他借下司书所荐之书，于借阅簿签名。见前人笔迹古旧，知此处访客稀少。
 ——至于缘由，筑宫日后方知。
>
# 茶毕，女史似尚有话，筑宫却决意告辞。
>
# 临别，司书唤住他。
 他驻足，疑有他事。她递来一硬卡——确为厚质纸片，如正式请柬所用。
 茶色底衬似其手套，边缘或饰金箔。然更令筑宫惊异者，乃其上以典雅花体书就己名。
>
#【司书】
「此乃本室会员证。
 ……再访时，请出示此卡。」
>
# 她语气郑重又微赧。筑宫反复比对卡片与她。
 罗马字姓名应源自借阅簿，顺序尚可。
 然那花体字迹繁复精巧，绝非他签名后仓促所制——
 且他未见她书卡。
>
# 传说林中小径遇绝色，共度良宵获赠信物，归途怀中却化为树叶——此乃狐魅常技。然真狐所赠，必似真金，否则易露破绽。
 反推之，此卡当为真物。若系伪作，经他如此审视，早该现形。
 然他仍不安，将卡片藏入衬衫口袋时，心绪难宁。
 故而——
>
#【司书】
「若寻得你那本书的线索，定会告知。」
>
#【司书】
「若得闲，再访无妨。
 随时欢迎——」
>
# 她轻颔首，伸手抚过筑宫面颊——此别礼于司书与读者而言，未免亲昵过甚。
 他仅含糊应声离去。待门扉轻合，心稍定，回思：她所触乃左手——义手！\t可那指节分明柔滑屈曲，动作自然无碍？
 ……指尖虽离，余温犹存，扰人心神！
>
