# 取回遗忘的信件重新放入口袋，一边擦拭因自己粗心而渗出额头的汗，筑宫一边朝返回账房的小姐背影低头致意。
 他随即望向水面——那如宝石切面般闪烁生辉的水渠，陷入沉思。
>
# 信的内容大致明白了，但关于收信人的线索却几乎全无。那位似乎被倾慕的男性特征也极为模糊。
 这要送信，简直是水中捞月。况且，这旅笼中到底有多少男客？
 挨个排查，并非现实的手段。若问这与某收容所让囚犯反复挖坑填土的苦役孰更甚，恐怕一时也难以作答。
>
# 况且，沉迷于这等虚无缥缈的信件碎片，简直如同梦野久作的小说一般。自己难道不该有更重要的事要做吗？——青年自嘲地苦笑。
 比如努力恢复失去的记忆，比如设法回想自己的过去，比如弄清这来路不明的自己该何去何从，等等等等。
 换种说法，其实都是同一件事。这般文字游戏，不过是逃避现实的一种方式。
>
#【清修】
（逃避？我在逃避吗？）
>
# 不知不觉间，一股窝囊感沿着脊背爬上来，仿佛在肩头喋喋不休地嘲讽。青年一烦，便踢向脚边一块陶瓷碎片，将其踢入水渠，扑通一声，水花四溅。
>
#【清修】
「总之，还是忘了这封信为好……」
>
# 他之所以自言自语，正因话虽如此，心中却莫名地对那信念念不忘。
 仿佛喉中卡了小刺般的不快挥之不去。归根结底，是这水渠把瓶子带到了自己跟前——他正以毫无道理的怨气瞪向水流时——
>
# 水渠前方，在蜿蜒曲折处，露出了小舟的船头。
 似乎是船女，今日也在旅笼各处穿梭。
 他忽然想到：何不问一问船女？水渠是她的领域，而且那位戴着破裂般若面具的奇妙女子，似乎对旅笼的种种都颇为了解。
 若能借她的智慧，或许能有办法——筑宫停下脚步，准备等候小舟。
>
# 『嘎』，桨声响起，『吱』，船头磕碰走廊的声响叠加——本应等候小舟的筑宫，却已闪身躲进了附近的房间。
 只因小舟船头端坐着的人，正是图书室的司书女史。那宛如女神船首像般端庄的面容，任由穿行于水渠的微风拂动发丝。
>
# 筑宫对司书，怀有敬意、少许敬畏，以及对那丰美肢体的情欲，交织成一种微妙而朦胧的倾慕或好感。他本不是那种需要躲躲藏藏、心怀愧疚的人。但唯独这次，口袋中鼓囊的信件令他远离女史。
 最初未能坦率相告、隐瞒了信的事，这份负疚感让他犹豫与女史正面相对。
>
# 即便如此——他一边小心不让自己的影子落在纸拉门上，一边透过细缝窥视小舟的动静。
 在图书室以外的场所看到司书女史，总觉得有些格格不入。她昨天刚来收过逾期未还的书，按理说，没有多少事会让她离开图书室那『寄居蟹』般的壳。
 在青年暗自揣测究竟有何用意之时，小舟已然驶至他藏身的那间起居室跟前。筑宫愈发小心地屏住呼吸，竖起耳朵，试图从话语的间隙中捕捉些什么——然而司书端然静坐，默然无言；渡船人亦悠然摇橹，同样不言不语。仿佛『三人相聚便喧嚷热闹，但少了一人便不成局』一般，两人之间竟无一句往来的话语。
>
# 虽不像是气氛险恶，但两人都如成年猫科动物般孤高地分立船头与船尾。想来，这种个性强烈的女子，气场恐怕会互相排斥吧。
 说起来，司书女史被称为鬼女，筑宫也隐约觉得那是事实；而摆渡人所戴的破裂面具正是般若——若不计较细节，那也算是鬼面，因此也可谓鬼女。或许两人同处一处，个性会重叠，故有意保持距离。正当青年转着这些无聊念头时——
>
#【司书】
「……咦……？」
>
# 她做出仿佛侧耳倾听、又似嗅闻气味、亦如眯眼细看的表情，朝向了他藏身的房间。虽说不像已被发现，筑宫却不由得缩紧了身子。不，隔着一层薄薄的纸拉门，气息恐怕很容易就被察觉。
 对方毕竟是鬼女。
 『快，快驶过去吧』——他连呼吸都小心翼翼，更不敢动弹。小舟的移动在他感觉中比蜗牛还慢，但终究还是驶过了房间前方，船尾也渐渐远去。
>
# 他正想大大地松一口气，却硬生生忍住，悄悄探出身来。就在这时，他的耳朵捕捉到了：
>
#【船女】
「这一带不错。
　从这里上去，离账房近。」
>
#【司书】
「多谢。
　帮了大忙。」
>
# 这是两人之间首次传来的对话。
 他忘乎所以地将耳朵贴在纸拉门上，却只听到小舟嘎吱作响、以及踩踏地板的脚步声——看来司书已经下船了。
 随后小舟也远去，只剩下溪流的潺潺声。然而筑宫却陷入了疑虑。
>
# 看来司书是往账房去的。可她到底有何事需要特意跑一趟？
 他可从未听说司书与小姐有什么亲密的往来。
 莫非是追着自己来的——？筑宫一边用指甲无心地划着纸拉门的横档，一边闪过这个念头，随即又试图打消，但那想法却迟迟无法散去。
>
# 莫非司书是为了那封信，正追着他、寻找他可能去的地方？
