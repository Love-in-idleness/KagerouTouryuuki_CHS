# 旅笼内，那回环曲折的走廊与房间连绵，本身已是令人流连的风景，但有时，眼睛也渴望那平坦而无遮蔽的广阔。
>
# 旅笼几乎齐备了筑宫所需要的一切，可唯独屋里，提供不了那种视野——
>
# 于是，青年便——
>
# 穿过了码头，走向那面朝大河的栈桥。
>
# 筑宫抵达旅笼的当晚，大河据说因夜雨而涨水，可此刻，它不留一丝狂暴的痕迹，静谧得仿佛一片海。风平浪静，广阔流淌，微风穿行。
>
# 栈桥的尽头，泊着一只小舟，那位戴着裂面般若面具的船女，正和筑宫一样，凝望着这条大河，这并非筑宫所期待的巧遇。
 她不像青年那般空手而来，而是如姜子牙般垂钓，把鱼竿伸向河心。
 筑宫并非想惊扰她，为免惊走鱼儿，他尽量不让木板发出声响，悄然走近，轻声启问。
>
#【清修】
「可有鱼儿上钩呢？」
>
# 这句问话，是古往今来钓者与看客之间，重复了千百万次的俗语。筑宫从自己口中吐出时，感到一种对传统略带羞涩的意识，他将这问询抛给了船女，
>
#【船女】
「哦？啊啊啊……？」
>
# 筑宫的声音，竟与她正欲收竿的瞬间，以一种奇妙的方式重叠了，使得船女的动作，显出了她少有的轻率。
>
# 鱼竿倏地一颤，鱼线绷得笔直，显出有物挂在钩上的重量，却无鱼挣扎的脉动传来。
 这意味着，并非成功钓到鱼，而是鱼钩被水底的什么东西，『根挂』住了，难以拔出。
>
# 筑宫心头一沉，为自己的多余言语，在多余的时机，感到一阵憮然的歉意。
>
#【船女】
「哎呀，筑宫老爷。
 您稍等片刻。
 钩子被什么卡住了」
>
# 船女并未因此责怪筑宫，她只回望了他一眼，便开始用力，试图解开根挂的困境，她时而提竿，时而手摇线轮。
 筑宫心中涌起一股无谓的责任感，他甚至开始想，若钩子仍旧不脱，自己是否该潜入河中去解开它。就在这思虑之际，竿尖忽地一跳，仿佛骤然变轻，鱼线的绷紧感也稍稍松弛。
 看来是幸运地脱钩了。
>
#【船女】
「哦，取出来了，取出来了。
 ……不过，好像还挂着什么东西。鱼钩沉甸甸的」
>
#【船女】
「鲶鱼啊，或者婆鳅之类的，底层的鱼，手感就是这般沉重。」
>
#【船女】
「是它们就好，变成那样的鱼吧，成为今晚的下酒菜吧……」
>
# 船女如同念诵咒语，将鱼竿高高立起。筑宫也被牵引着，凝视着水面上微微颤动的线头。
 鱼线迅速上升，最后，船女将它一气呵成地拔出水面；那破水而出的东西，带着一层浅淡的茶色。
>
# 然而，它对于鱼而言，过于浑圆，既没有鱼鳞的闪光，也没有挣脱鱼钩的挣扎，它只将三个空洞的孔，向世界敞开——
>
#【清修】
「等、等等……哇啊啊啊！？」
>
# 筑宫瞬间明白了它的真面目，他猛地向后跳开，险些从栈桥边缘跌落。
 ……不过，对于未曾见过之人，这反应算不上过度，毕竟，想来世上也没多少人对此习以为常。
>
# 那在船女拉起的鱼线尽头，像吊井的木桶般，缓慢上下摇晃的东西，正是——
 ―――一颗髑髅。
 它看来已沉寂许久，皮肉皆已被水流洗净，只剩泥泞从眼窝和鼻孔里滴落。
>
#【船女】
「这是什么，一个骷髅啊。
 真是个不该出现的『渔之外道』啊。」
>
# 尽管钓起了这样的东西，船女却平静得出奇。筑宫强迫自己心平气和，怀疑是否只是自己胆小如鼠，而非这女子心性如铁，但面对骨头，尤其是这不祥的头颅，他实在难以平静下来。
>
#【清修】
「……看起来，是很古老的骨头了……您打算怎么处理它？」
>
# 声音中的厌恶，青年已无法抑制。他期望船女能立刻将此物扔掉，可她不仅没有抛弃，反而——
 船女从怀中取出一条手巾，将那仍旧滴着水珠、涔涔下淌的髑髅，举到鼻尖，开始仔细擦拭。
 筑宫皱紧了鼻翼，仿佛闻到了醋味，心想这真是匪夷所思，如同那位施洗者约翰的头颅。
>
#【船女】
「哎呀哎呀。
 别这么讨厌它嘛。」
>
#【船女】
「它在冰冷的河底，沉寂了这么久，难道不可怜吗。」
>
#【船女】
「若不好好超度它，
 也许会滋生出奇怪的妄念。」
>
# 船女与筑宫的态度截然相反，她丝毫不觉得这髑髅可怖，她拭去水渍和深泥，用手巾包裹起来，然后轻轻放入了船舱。
>
# 伸向大河的栈桥，是天地与水流交界的所在；小舟微微摇晃，船女脸上的般若面具一如既往；那从水中打捞起的髑髅，也已被妥善收起，万事回归平静。筑宫不禁怀疑，在这一连串的景象中，自己是否才是多余的异物。但他竭力让声音保持平稳，再次发问。
 他不愿表现出丝毫的畏惧，怕一个大男人，显得过于怯弱。
>
#【清修】
「这么古老的骨头，真能寄宿什么妄念吗……难道不会，如同字面意思，早就随水流逝了吗？」
>
#【船女】
「哪有这回事。人死之后，
 妄念遗留在骨头里，是常有的事情。」
>
#【船女】
「即便经过火化超度，
 皮肉和内脏都化为灰烬，
 可骨之精魂却会留下。」
>
#【船女】
「谁也不知道，那里面寄宿着，怎样的心愿未了。」
>
#【船女】
「所以，才要好好地，超度它啊。」
>
# 收好髑髅，船女似乎再无意继续垂钓，她取出一支银质长烟管，填满了烟丝。
 她缓缓吐出一缕青烟，问道：
>
#【船女】
「话说回来，老爷，您有什么事吗？
 莫不是，想渡河？」
>
# 筑宫被问及，重新遥望大河的远方。视线虽毫无阻碍地延伸，但大河的尽头，却消融在一片朦胧的雾霭之中，即便天色晴朗，景色也无法更清晰地分辨。
>
#【清修】
「不……不是。
 至少眼下，我并没打算，让你把我带走。」
>
# 筑宫在说出口时才意识到，他尚未达到，启程离开旅笼的心境。
 旅笼的日子，眼下确实平静无波，清闲得让人无所事事。然而，他此刻却首次感到，这种一帆风顺的日子，仿佛是暴风雨前的宁静，或是大戏开场前的预备期，这感觉是为何而来？筑宫自己不得而知，反倒是船女，露出了然的神色，点了点头。
>
#【船女】
「哈哈哈……老爷您要继续逗留，我倒是一点也不介意。」
>
#【船女】
「可是，是否有，什么让您挂心的人或事，在此间诞生了呢？」
>

# 是那小姐的倩影。
 那位旅笼一族的末代后裔，她的面容既出众又典雅，带着一种拒人千里之外的疏离，但偶尔，却会流露出一丝，疲惫而寂寥的色彩。
>
# 是那位人称『图书室鬼女』的司书的模样。
 筑宫起初，并不相信她极好年轻男子血肉的传闻，认为那是无稽之谈，但事到如今，却也觉得，那传言，似乎正道出了某种真相。
>
# 诚然，她令人畏惧，可即便如此，筑宫却已开始感受到，自己被她身上，某种神秘的力量所吸引。
>
# 是在温室中相遇，又在酒馆亲眼目睹其弹奏技艺精湛的琵琶法师的音容。
>
# 她若说愚昧则愚昧，若说纯真则纯真，无论如何，都是个不食人间烟火的女子，但她那份亲近感，却如影随形，紧紧缠绕着筑宫的心，不肯离去。
>
# 如今，筑宫已开始考虑，找个时间去温室，或她的庵里拜访。这思念，已是无可否认的事实。
