# 夜半――
 从睡眠的深渊，微微浮上浅滩，在那般时分筑宫自然而然地睁眼，发觉自己正盯着陌生的破旧天花板。
 初醒时胡乱的心，只顾讶异自己身在何处、为何用着这般单薄的被褥。惶惶然环视房间之际，记忆才渐渐苏醒过来。
>
# 说是『煎饼』或许显得太过荒唐的，但这确实是磨得薄透将破的铺盖。而飘浮其上，却是那无可混淆的、隐忍般的甜香，年轻女子肌肤的气息。
 筑宫本应会忌讳，忌讳自己这副粗野、满是男人汗臭的身躯，不该如刺穿宵暗中白粉花的庭园那般闯进来。但事到如今再介意，也无济于事了罢。
>
# 是的，筑宫这位青年，暂借了这寂寥住处的主人——琵琶姑娘的睡铺。毕竟已与她肌肤相亲过了，既然如此，此刻又何须在意女子的气息呢？他又不是那种闻到姊姊或妹妹镜台的白粉味，便觉局促不安的小少爷。
>
# 总之，这里是法师的庵室，自己似乎是被情事后四肢蓄积的慵懒重力所牵引，就那般沉沉睡去了，可是那位法师去了哪里？
 行灯或许油尽了，庵室被柔和的黑暗所填满，但习惯了黑暗的眼睛倒也不觉得多么晦暗。
 环视四周，并非什么需要费力寻找的宽敞宅邸，却不见她的身影在地面或板间。说起来，青年之所以醒来，不正是因为翻身时手臂扫过，徒然掠过了独眠的床铺，察觉到的那份异样感么？
 入睡时，明明确有柔暖的触感依偎在身旁的——正以夜半独醒于黑暗中的、幼子般的心绪撑起半身时，筑宫听见了。
>

#
 ——宛如自黄昏的窗内，聆听缓缓经过的旅人足音一般，断断续续的、却又清亮的技艺，那弹拨之音将法师显现得比旅券上的相片更为鲜明。
 这声音来自庵室之外，而筑宫之所以未能立刻出声呼唤，是因为即便隔着板壁，也传来了某种非同寻常的气息。
 并非法师，而是似是有什么在骚动着、群集着的，一种可疑而不明所以的气息。
>
# 许是因睡意未消，手臂沉重，双腿虚浮，他缓缓挪动着身躯，自庵室后门窥探出去。
>
# 他总算勉强忍住了——险些『啊』地失声叫出、扰乱琵琶清响的那股冲动。
 然而，即便如此，他还是深深倒吸一口气，随即僵住了。
 ——青年甚至觉得，自己是否仍在梦寐之中，正被梦魇所困。
>
# 庵室后侧，法师常行沐浴的水渠边，在那板铺上，反扣着筑宫也曾浸浴过的大木盆、盘腿而坐弹奏琵琶的法师——若仅是如此，倒还无妨。
 她或许也是夜半醒来，难以成眠，于百无聊赖中独自吟弹琵琶罢。
 若将这静谧旅笼的一隅，只留给法师的身影，那倒也算得上是饶有兴味的景致。
>
# 然而——
>
# 这夜半水畔展开的情景，是何等异样啊。
 ……美之观念并无绝对标准。若问人从对象中何以见出美，那大抵在于整体之中，蕴含着多少和谐罢。不同的美感，即是不同的协调性。
 仅抱着琵琶的法师与森然寂静的旅笼夜色，确然和谐，彼此映衬、相辅相成，是堪可纳入画框珍爱的景象。但此时，却有污浊景致的杂质混入其中。
 混杂着，蠕动着，企图覆盖一切，将和谐古怪地扰乱。
>
#【清修】
（那是……什么？）
>
#【清修】
（活物……不，怎么可能……）
>
# 青年本想以为那是自己尚不知晓的水生之物爬了出来，却又立即否定了。不论这旅笼何等广阔、隐藏着他未知之物的可能性有多大，那等古怪之物，断不可能与呼吸存活之物同存于世间常理之中。
>
# 自水渠中——
 哗啦、哗啦地昂起头，伸长、试图爬近而来的，是比夜更浓的、仿佛熬煮过的墨汁垂滴而下般的漆黑、某种粘质的物事。
 某种，只能如此形容的、无以名状的物种。
>
# 诚然，一到夜晚，旅笼的水渠便被夜的帷幔染暗了白日清澈的水面。
 但那东西，比映在水渠中的夜更黑，是凝固般的色泽之物。
 自水渠中湿漉漉地伸出，在板铺上黏糊糊地蔓延开来，形状不定，轮廓模糊。
>
# 四周笼罩着如水渠流声都已停滞般的妖异寂静，筑宫青年耳中，自己喧嚣的呼气与心跳清晰可闻。
 正因这般寂静，琵琶声愈显清越，法师的吟唱愈发澄澈，可闻之声仅此而已，然而筑宫却对那东西可能发出的声响感到恐惧。
 不，实际上它并未发出任何声响。但是，那蠕动，那蠢动，仅只目睹便似有丑怪的声响自视觉传递而来。
>
# 如同揉捏泥泞般猥亵，如同舔舐嘴唇般淫靡，以令人感到黏腻声响的动势，朝向法师，抬起那墨色触手般难以名状的、颤巍巍抖动的尖端，匍匐逼近。
 再看罢，那粘块的各处甫见隆起，漆黑表面的上方，不是浮现了小小的人形么？
 被黑色吞没，谈不上什么眉目，以铅笔般的身高与相称的四肢悬垂着，在粘块各处形成一个、两个三个，其后数之不尽、无数成形。
>
# 那样的东西，抬起手臂，摇着头颅，在墨色的流波上爬行着，向法师迫近。
 她是否察觉到了呢？
 只是浑然忘我地拨弄琴弦，低低地、细细地，如同呓语般吟唱而已。
>
# 筑宫未能踏出一步，既是因那异界妖异的景象令四肢几近麻痹，却也因即便在此刻，仍被法师的技艺与本嗓之美夺去了心神。
 然而，当墨色粘块迫近至法师脚踝咫尺之处，倏然膨胀，将不定形的尖端如作威胁般递出时，那般咒缚亦被打破，他正欲如脱缰之犬般猛冲上前，却在吐纳被夺去般的刹那——
>
#
 \t\t\t——袅——
>
#
 强烈鸣响的琴弦，余韵悠长，以甘美而战栗的颤意浸染夜气。仅仅一音，何以能拥有如此丰盈的回响？实在不可思议。
 这一音，挫去了筑宫的气势，令他踉跄顿足，但显露困惑的并非仅他一人。
>
# 方才正欲缠绕法师脚踝的墨色粘块，黑色的小人们，亦如同被琵琶的一音所阻，停止了动作。
>
# 袅、袅——弹拨的琵琶音色澄净，吟唱的嗓音亦卓绝，筑宫一时竟忘了奔上前去，侧耳倾听，继而一瞬，又数瞬，连法师的危机也忘却了。
 啊，不行——他摇首欲挥散音曲的魅惑，然而错失介入时机的青年，眼前所见的却是——
>
# 在即将触及法师前静止的粘块。
 正微微地、微微地搏动着，仿佛应和着琵琶妙音，似乎已然忘却了进一步逼近法师。
>
#【清修】
（那莫非——）
>
#【清修】
（听得出神了？）
>
# 那墨色粘块与小人们，本应绝无分辨音律的耳朵可言，但青年如此感觉，未必是他凭空臆想。
 它们环绕着持续吟唱的法師，表面不时波动，确乎是一副听得出神的模样。
>
# 歌声流淌，音韵连绵，法师只是闭目凝神、浑然忘我地吟弹着，仿佛丝毫未意识到自己被何等古怪的听众所环绕——如许时光随着曲调流逝——
>
# 是该为危机而紧张，抑或该效仿墨色妖异、恭谨聆听呢？这般微妙的平衡，因粘块再度开始动作而被打破。
 筑宫又一次绷紧身子，但与他的忧虑相反——粘块们，竟退却了。
 滑溜溜地，远离了法师，而后如同将爬行而来的过程倒转一般，被吸入水渠，沉入流水的深处，隐没于黑暗，是向上溯洄抑或向下流去，已不得而知。
 退去得如此干脆，方才的异样气息也已消散殆尽，耳中所闻唯余水渠潺潺的细响。
>
# 寻常的声响，回来了。而法师，也停止了琵琶的吟弹。
>
#【法师】
「哎呀……你也听着呢，筑宫先生。
 ……是我吵醒你了么？
 我是不是……做了什么不好的事呀……？」
>
# 说着，将琵琶置于身侧，仰起脸，带着些许歉然、些许羞涩的神情，在胸前将两根食指轻轻对碰着。
>
# ……带着某种如饮了可疑酒水般的醺然心绪，筑宫终于走到法师身边，只见她已丝毫不露方才那种近乎神性的气息。
 自然，墨色的粘块在周遭连一丝碎片也无，筑宫甚至怀疑片刻前的情景是否夜的幻影，于是开口问道：
>
#【清修】
「不，并非被你吵醒之类。只是不知怎的，忽然就醒了……这才过来瞧瞧。」
>

>

 是什么呢，那个。」

#【法师】

>

>

>
#【法师】

 刚才的，大概就是那一类罢。」
>

「听说过是听说过。但这说法，似解释又未解释清楚。」
>
# 将那异样之物归为妖怪、物怪之流，虽似过于顺理成章反不成解释，但法师似乎也无更多言语可述。
>
#【法师】
「这旅笼里，好像时不时就会出现那种古怪东西呢。我也遇见过几回。」
>
#【法师】
「……不过刚才那样的，倒是头一次。」
>
# 诚如法师所言，这旅笼古老而宽广，潜藏那类妖物的缝隙可谓数不胜数。想来筑宫青年初抵旅笼之际，不也曾遭逢类似的迷惑么？
>
#【法师】
「嗯，虽然有点毛骨悚然的，不过据说呀，它们只是吓人而已，不会对人做什么坏事的……」
>
#【法师】
「听说就算遇上了，不久也会自行消失，所以不必太过在意的。」
>
#【清修】
「被你这样一说，也只好姑且信之了，只是……」
>
# 点头应着，言辞却有些吞吐，倒非怀疑法师的话。
 的确，方才的墨色粘块与黑色小人们，虽令人悚然、异样，却并未加害于法师。
>
# 然而筑宫青年总觉得，它们并非自然消逝，倒像是被法师的琵琶之音所迷，为其技艺所折服，因而退却了。
>
# ——这一夜的这一幕，虽费解且悚然，却在后来日复一日中，折叠进筑宫记忆的褶皱里，冲击也渐渐淡去了。直到某一天，以某一事件为契机，再度浮现于青年心湖的表面。
