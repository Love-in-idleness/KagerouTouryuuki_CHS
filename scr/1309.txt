# 虽与两人登上屋顶的那日下午不同，但同样是晴朗的好天气。树隙阳光在脸上投下斑驳，法师仰天而坐。
 密闭又宽敞的室内底部，积攒着温热的草气花香，如薄粥般浓稠，宛如热带。不习惯的人稍不注意，便会感到类似微醺于酒精般的酩酊感。
>
# 但法师常在此度日，早已完全适应温室温热浓稠的空气。她望着天窗外，如树木叶丛张开气孔般，轻轻鼓起鼻翼深呼吸。
 随即闭上眼，侧耳倾听，似要分辨什么。片刻后，远处极细微、真正极细微的，如针落地般的声音得以听清。这既有沉默充满温室的缘故，更因法师已等待多时吧。
>
# 她蓦地起身，小鸟般小跑至入口，将头探向走廊。外面的空气凉凉地触着脸颊，但冷却法师因期待而雀跃的心胸的，并非温差，而是失望——因为朝这边走来的人影。
 从走廊对面经过的，是似在办事途中、极其寻常（这么说对她或许失礼）的侍女。
>
# 话虽如此，即便来的并非侍女，而是某国贵族豢养的鹰匠之女：故乡正席卷革命血雨腥风，她险些成为断头台上的露水消失，如今与年幼的少主两人隐姓埋名潜伏于旅笼，至今仍为年幼的主人乔装打扮，刚从厨房窃取面包与葡萄酒归来……纵有这般隐秘戏剧，也未必能引起法师的兴趣。
>
# 已毋庸多言，法师等待的是筑宫。
 虽来到温室，却无所事事地竖起耳朵，每次走廊传来足音便匆匆窥探，每次又都失望，已非一次两次。
 有道是事不过三，亦云有二必有三，但法师如此因走廊声响从草席起身，已是第四次。
>
# 让女子这般等待却至今未闻其足音，筑宫倒也习得相当吊人胃口的手段了——虽非该如此责备。毕竟本未约定今日在此相会。
 只是法师独自焦心，或坐或立期盼青年来访，说可爱倒也可爱，但终究不太实在。
>
# 法师难为情地点头致意，侍女疑惑地回礼，被目送的法师显得何其百无聊赖。
 返回温室的背影低垂，连整理袴裾也无精打采。在草席上抱膝而坐的模样，如同被命令等待后主人却不知去向的狗儿。
 但并未长久消沉，很快又振作起来。
>
# 此前，在与筑宫相遇之前，法师仅以那块『请向我讲述』的木板为伴，日复一日独坐。
 温室的温暖空气是人为的，佐保女神不会为报春而到访，龙田女神亦不会带来秋意，但花朵依然绽放，果实仍会结成，流逝时光的长度可被计量。
 而法师只知淡然接受没有交谈访客的流逝时光，渐将独处视为理所当然，所以筑宫到来的那一刻，她真的——是的，发自内心地欢喜。
>
# 能与那样的青年交谈，能与那样的青年多次相见，能与那样的青年肌肤相亲情意相通。
 等待的时间远比认识他之前漫长，心绪虽骚动，但有所等待之人，是何等幸福的事。
>
#【法师】
（筑宫先生，
 教会了我许多事呢……）
>
#【法师】
（……还想，还想知道更多。
 想更了解你的事，
 也想多多地拥抱……）
>
# 愿望充满隐秘的喜悦，又因有心仪对象的幸福，法师唇边泛起如童女般的微笑，将琵琶抱在膝上。
 虽只不过是不曾为思念谁而弹奏，虽只是无心串联旋律的自己，但怀抱着筑宫青年面影弹奏的琵琶，将会奏出怎样的音色呢？她心怦然，拨动了琴弦。
>
# ――在温室内弥漫花香的气息中，袅袅琴音渐渐消融——
>
# 然而，弹奏数节后，拨弦的手渐显迟缓，终于弹响一音便停了。那音色不知怎地不清亮，拖得绵长。
 虽也可认为是原本曲调缓慢，但俯视膝上琵琶的法师，眉头疑惑地微蹙，看来她自己也不满意这调子。
>
# 实际上，若有具备乐评家听感的人聆听，恐怕会给予相当严厉的评价吧——就是这样的演奏。
 ――尤其，在弹奏琵琶一事上，拥有如神技般技艺的法师，竟会如此。
 她也重新调弦试试是否弦音不准，或将耳贴向琵琶琴身检查是否有扭曲，然后再次认真弹起，但——
>
# 曲调未能持续多久，持拨的手垂落膝旁。法师歪着头，一次又一次歪着头。
 唇间低语的，也非配合曲子的歌词，
>
#【法师】
「总觉得……不对劲……」
>
#【法师】
「听不见，了……？」
>
# 如此，有些奇妙的困惑之语。
 但究竟什么听不见呢？
 既然对自己的演奏不满，琵琶声不可能听不见，此刻温室某处气球状花苞绽开的微响，两只争夺树干渗出树液的甲虫摩擦坚硬鞘翅的声音，都传入了法师耳中。
 但法师仍低语听不见，朦胧眼神带着不安之色。
>
# 这个午后，温室再未响起琵琶声，法师只是孤零零地，以一反常态若有所思的神情，久久独坐。
