# ……青年惊愕复又困惑至极，只见大河之水，仿佛自『旅笼』的四面八方引入，纵横交错地流淌于这巨型建筑的内里。
>
# 在侍女的引路下，青年正行走于这般『旅笼』内部水路之侧的通廊。
>
#【侍女】
「您的鞋子请放于此处」
>
# 他将鞋履收入递来的布袋，换上对方准备的室内便鞋。
>
#【青年】
（这……是何等建筑……）
>
# 这般荒诞，令他怀疑自己是否真的身处室内，遂抬头确认，目光未及天空便被天花板阻隔，然其高耸。周遭确以柱、梁、带扶手的走道、木板楼梯等物什构成，昭示着室内的调性，但它们却无限延展、复杂叠层，永无止境。其尺度、其法度，与寻常宅邸相去荒谬之远。若说它如将古老样式的房间拼凑，聚成一座城，不如说它更似迷宫，一座立体的迷宫。
>
# 他就这般左顾右盼，眼神流连于各处，不知不觉被侍女拉开了距离，于是慌忙追赶。就像是初登都市运河的山中之蛙，为那复杂怪异所惊，翻倒在地。青年此时与那蛙别无二致。
>
# 侍女停下脚步，等候青年追上。
>
# 左拐右弯，上楼、下楼、再下楼，几番往复，青年早已忘记从泊船处而来的路径，而侍女却深谙其『道』，脚步似行云流水。正当青年开始疑虑路途之遥时，他们抵达了一室，似是这『旅笼』的账房。一张由岁月浸染得乌黑发亮的账簿桌居中，旁边的舟形柜、叠层架、落地钟等尽显大店账房气派。此处亦有一名侍女驻守，见引来的青年，起身行礼，道一声『欢迎光临』，然青年却对她的面容感到不解。他望向身旁，那位引路的侍女。
>
# 她们有着同一张脸。
>
#【青年】
（是双胞胎之类的吗）
>
# 倒也算不得稀罕，但同样的制服、同样的容貌，便添了几分异样心绪。青年深知凝视他人面容是失礼之举，却仍忍不住比较，这时，驻守账房的侍女将文宝盒与住宿登记簿滑至榻榻米上。文宝盒乃黑漆嵌螺钿之上等品，宿账亦是沉重有质感。册子内页，想必堆满了这『旅笼』的历史。
>
#【侍女】
「远道而来，辛苦了。那么，请您在此处填写贵名。」
>
# 文宝盒中是砚台和毛笔，青年理所当然地执起了笔，而侍女却略带歉意：
>
#【侍女】
「抱歉。眼下钢笔用的墨水恰巧用罄了。」
>
# 此话出自驻守账房之人。
>
#【侍女】
「若用毛笔书写不便，我去取替换墨水。
 届时还请稍候。」
>
# 此话出自引路之人。
>
# 两人轮番致歉，青年却再次确认手中毛笔的持握感，毫无不适。倒不如说，他已准备落笔在宿账之上。
>
#【青年】
「不……我想没关系。」
>
# 有一则寓言：若问一只空中飞翔的鸟儿如何飞翔，那它原先如呼吸般自然的振翅，将被过度的意识压垮，使得鸟儿立时无法飞翔。但青年的笔墨并未重蹈鸟儿的覆辙，自然地滑行。
>
# 笔尖轻触，旋即离开簿册，留下的墨迹尚带着洇开的湿润，赫然是：
>
# 
 \t\t\t筑宫\t清修
>
# 
 四个字。
>
# 那名字，自然而坦诚地浮出心底，这就是他的名字。它如贴身的内衣般熟悉，不，甚至如肌肤般，是他自身的一部分。他目光描摹，口中咀嚼，确认之后，深深吸了一口气。他试图以自己的名字为契机，再次牵引过往。
>
# 却并未能立竿见影。唯有自己的名字悬浮于心间，而那些能稍稍揭示他的往昔的记忆，一丝一毫也未曾苏醒。侍女来到在懊悔的筑宫身旁：
>
#【侍女】
「啊，真是好字呢。」
>
# 侍女由衷地赞美他的笔迹，然而筑宫本人却毫无感触。他评判自己的字，仿佛他者之事：若说工整，或许称得上，但仅是端正，毫无趣味可言。有言道，字如其人。若果真如此，那曾经的自己，岂非只是徒具表象，缺乏人性魅力的无趣之人？他为此心绪沉郁。不过是写字一事，这青年也未免太过消极。
>
#【侍女】
「请问，『tukimiya』……是这样读吗？」
>
#【清修】
「啊，正是。
 我叫『tukimiya seisyuu』。」
>
# 名字似乎未曾遗忘，但这并未使他的心境有一丝明朗。
>
#【清修】
「非常抱歉，我似乎失去了过往的记忆。除了名字之外，住所、职业之类，都无法填写……」
>
# 筑宫偷偷打量着侍女们，心想非医生之口说出失忆，是何等缺乏说服力。这不啻于暗示自己是身负恶名、无法公然自证身份的凶徒吗？然而两位侍女并未流露丝毫怀疑，只是：
>
#【侍女】
「以前的事，全然不记得了吗？」
>
#【侍女】
「啊，那真是太不幸了啊……」
>
# 她们同情地附和，并未进行筑宫所预料的追问身份。这反应出乎意料地随便。察觉到他有些失落，侍女翻开了前页。
>
#【侍女】
「其实，那部分不必勉强填写。瞧。」
>
# 宿账上，并列着历往客人的各种字迹、各种语言（其中不乏筑宫完全不认识的外国文字），但许多人也仅填写了姓名。
>
#【侍女】
「只登记名字的客人也非常多。」
>
#【清修】
「原来如此……」
>
# 竟有如此宽宏的旅馆，筑宫反而为此担心：这样随便真的可以吗？就在此时，
>
#【侍女】
「那么，对房间方面有何期望吗？」
>
#【清修】
「咦？不，呃，不，怎么说呢……」
>
# 被突然问及，筑宫支吾着，认为自己没有立场挑剔房间。毕竟，他根本不知此处有何种房间。
>
#【侍女】
「既然如此，就让老板娘来决定吧。」
>
#【清修】
「全凭吩咐。」
>
# 筑宫将选择权托付给他人。经历了接二连三的惊奇，他其实此刻已开始感到些许疲惫，但他仍不露声色地保持着礼数。在等待着那位收拾桌子准备引路去房间的侍女时，他环顾账房内的一切——目光相遇了——与一位在门口探头张望的侍女的目光相遇。
>
# 她是侍女中好奇心重的那一类，似乎在品评新来的客人。筑宫反射性地行了一礼，行礼之后，他下巴猛然垂下，看向身旁。将他引至此处的侍女正安静地站在一旁，而另一位正在柜台重新摆放账簿工具。他本以为那两张相同的脸，大约是出自双胞胎，那么，此刻站在门口探头的，那第三张一模一样的脸，又是怎么回事？
>
#【清修】
（三胞胎——！？）
>
# 虽知有此可能，但现实中罕见，他的目光无法遏制地转向好奇——
>
#【清修】
（？\t！？\t！！）
>
# 从那位毫不羞赧地继续窥视的侍女身后的走廊，又横穿过了另一位侍女。青年瞥了一眼，那张脸，依然相同，用『毫无二致』来形容也不为过。
>
#【清修】
「啊？这……等、诶诶诶！？」
>
# 哪有这么巧合的四胞胎故事。此刻他也顾不得什么礼数，目光眼花缭乱地在柜台、身旁、门口的侍女之间旋转。他甚至情不自禁地一编制一边喊：『那边、这里、还有那边』。
 柜台的侍女一开始疑惑地看着他，随即恍然大悟，击掌道：
>
#【侍女】
「您好奇吗？」
>
#【清修】
「这怎么可能不……你们是姐妹吗？三胞胎，四胞胎之类的……？」
>
#【侍女】
「不是哦。」
>
# 如此干脆的否定让筑宫更加困惑，不过这份疑惑亦是情理之中。毕竟，像是一个模子刻出来的容貌接连出现，任谁都会怀疑自己的眼睛。非亲非故者有此相似更是不可思议，他等着对方如何解释，但那侍女却轻描淡写地说道：
>
#【侍女】
「不必深究。
 我们就是这样的存在。」
>
# 『就是这样，仅此而已』，然而，即使给出比着稍稍合理些的说辞，他是否能接受也存疑。谜团仍是谜团，筑宫只能怪异地颔首，接受『就是这样的存在』。
>
# 筑宫又想到了更深一层。刚才她说的是『我们』，那是否意味着……这『旅笼』的所有侍女，都共享着同一副容貌？在泊船处，因距离远而不甚分明，但若思及那里的她们也都是同一张脸，筑宫的怪异之色便更深一层。
>
#【侍女】
「那么，我们走吧。请跟着我……啊，你，后续就拜托了。」
>
#【侍女】
「是是。换班了嘛。」
>
# 驻守账房的侍女，与先前引路的侍女交替，陪同筑宫离开房间。虽是交替，但因容貌相同，毫无更换之感。看来，这不合理之处，只能全盘接受了。
>
#【清修】
「……」
>
#【侍女】
「您很快就会习惯的。」
>
# 随行的她似乎理解了筑宫不悦的内心，轻松地说道。筑宫回头看去，心想真是如此吗？送行的侍女们，果然也都是同一张脸。
>
# 这光景，除了称之为超现实，别无他言。
>
