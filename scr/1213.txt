# ——缢鬼——
>
# 
　时间似乎是午后，昏昏欲睡、像要融化般的慵懒感弥漫了整个下午。而筑宫深陷其中的椅子，坐感令人陶醉——若有人能在这椅子上不打瞌睡，那想必是被神明罚夺了睡眠恩惠的可怜人吧。
>
# 这样说来，简直像是青年再度被那文箱化身所诓骗时的重演。然而，状况往往通过重复而向下一阶段推移，这是常有之事。看似完全相同却总有某处微妙不同——但事情未必总朝好的方向发展，这便是现实的严苛。这个午后的筑宫醒来时，并未像那时般被叶隙阳光轻抚脸颊般安详。
>
# 岂止如此，甚至可以说这清醒来得彻头彻尾地凄惨。可若说因为醒来时那股难受劲儿就想逃回睡眠的深窖里去，那也恕不奉陪——说不定从睡着那会儿起，就已经被梦魇缠上了呢。
　他不快地眯起眼，打出的呵欠连自己都觉得带着腥气。明明是安详的午后，却无端地感到凄惨。
　这窝囊感究竟是怎么回事。
　并非因不自然的姿势让身体各处嘎吱作响地疼痛——也不是因睡眠不足而头痛。只是纯粹地，心情低落。头顶仿佛被比工业都市煤烟更浓浊的忧郁之云盖住，重重地压下来。
>
# 筑宫万万没想到会在这图书室迎来如此阴暗消沉、忧郁压抑的觉醒。这糟糕无比的心情究竟源自何处，他全然摸不着头脑。他试图探寻心中是否有困扰自己的烦恼或不安，却完全无法集中精神。
　不仅如此，自己正被这忧郁侵蚀全身，而旅笼却悠然自得地享受午后——这情形令他恼火。椅子的优美曲线、书脊下端探出的书签绳那副调皮模样、书架上如熔化玳瑁般的清漆在温吞的午间空气中微微散发香气——这一切，甚至连空气中的一粒尘埃，都仿佛在用粉碎的忧郁铸成的锉刀，逆向地搔刮他的神经。
>
# 当周遭的一切都以不愉快迫近时，已不是恼怒，而是凄惨，甚至近乎悲哀。筑宫几乎连呼吸都觉得厌烦。
>
# 一旦意识到忧郁，连那仿佛量身定做的舒适椅子的坐感也变得违和，令人想粗暴地踢开它站起来。说起来，屁股坐着的附近似乎也有种异样的触感——是不是口袋里塞了什么东西？他正想确认，耳中捕捉到一阵沉重的声响。
　是从司书室门后传来的，似乎正在搬动什么大件物品。
　看来司书女史正在忙碌，或许需要男人的力气。
>
#【清修】
「那个……如果要搬什么东西，我来帮忙吧？」
>
# 筑宫一心只想逃避缠绕自己的忧郁，朝门后扬声道。他希望活动活动身体、彻底清醒过来，或许能驱散一些这最糟糕的心情。
>
#【司书】
「多谢费心。
　不过没关系。我一个人能行。」
>
# 然而回答却很冷淡——不，与其说是冷淡或疏远，不如说她确实无需劳动筑宫之手。即便如此，筑宫还是感到一种如同被抢走点心的孩子般的、悔恨与痛切交织的心情。
　况且，本是女史邀他来的。今早在房间醒来时，书桌上不知何时已放着一张潇洒的留言卡。边缘装饰着与图书室会员证相同的草花纹，无需推理便知是谁留下的——署名是『司书』。
>
# 留言写的是：
 
『有有趣之物入手，
　若蒙驾临，幸甚至哉。』
 
 措辞简洁却引人好奇。筑宫在旅笼中本无急事，心想司书女史若能提供消遣之物，便欣然前往。女史虽笑脸相迎，但寒暄两三句后便说有事准备、躲进司书室再未出来。他在等待中打了个盹。
>
# 让人等了又等，却连帮手都不让做——他正要起身的腰又颓然落回椅子。这时屁股口袋附近又传来窸窣声，更助长了青年的不适。
　他正要掏出里面的东西，却被司书室门打开的动静吸引了目光。
>
# 『唔』地现身的，是一片黑色。那颜色仿佛正好用来盖棺材——第一印象便如此阴郁，也是因当下心境所致。但那其实是一块大板状物，比棺材薄，里面被因黑布覆盖，看不清内容。其高度勉强能通过司书室的门，长度足有两间多。当那物件被缓缓推出，最后跟着出来的司书女史，连筑宫也不禁咋舌。
　重量单看难以判断，但从体积看绝非成年男子轻易能搬动的东西。可女史搬动时，衬衫的肩线丝毫未弯，依旧优雅。那姿态令人联想到神殿中不畏风雪的白色大理石柱——但同时，也不禁让人联想到搬运比自己大数倍的树叶的蚂蚁。
>
# 女史将黑布覆盖的板状物搬到图书室空旷处，暂且放下——从地板的嘎吱声来看，确实分量不轻。她单手巧妙保持平衡防止倾倒，排好三盏支架，将板抬起、嵌入、固定，随即拍了拍手，一副轻松完成的样子。
>
#【清修】
「这是……什么？」
>
#【司书】
「是什么呢？
　你到对面去看看。」
>
# 好奇心略胜于忧郁之重，筑宫问了一句。司书让他绕到板对面，却仍盖着黑布。
　他依言绕过去，女史随手揭去黑布，毫无故弄玄虚之感，反而让人有些不得劲儿。
　筑宫本以为会被展示一幅司书喜爱的画作——或是九相图。那描绘逝去美人肉体盛衰的画卷，从第一张仍如生前般丰丽，到后续逐渐腐败糜烂，据说是为启蒙佛法无常观而作，却无论如何难逃恶趣之讥——定是那种东西吧。他竟作了如此阴郁的揣测，事后连自己都觉得奇怪：为何会往那么不祥的方向想——
>
# 然而那里，什么也没有画。
　不如说，它是透明的。
　毫无指纹或油脂污痕，黑布下隐藏的，是一块巨大的玻璃板。
　透亮的玻璃板对面，司书女史正在整理衣装。
　磨得极好，仿佛散发冰凉寒气，虽则漂亮，但这便是女史所说的『有趣之物』吗？
　筑宫实在不觉得这有多大不了。若只是通透，女史的眼镜也是一样，甚至眼镜的造型更美。
>
# 想必有某种缘由，他会得到解释——他在玻璃前等了一会儿。女史却毫不在意他的焦躁，只是取下眼镜呵气拂尘。他终于等得不耐烦了。
>
#【清修】
「……这到底是什么名堂，能不能请您说说？」
>
#【清修】
「若要我帮忙擦，我倒不介意，但这玻璃板看起来一点也不脏。」
>
# 青年略带反话意味的抗议，女史并未不悦，只是招手。
>
#【司书】
「差不多了吧。
　你过来这边。」
>
# 又要绕过去——我又不是被肉吊着的狗。难道是在戏弄我？他差点要发作，这对平日温顺的筑宫而言实属罕见。他自己也对此感到困惑，强压着怒气绕到女史身旁。
　司书微微点头，像是示意般地望向玻璃板。可青年觉得，无论从哪边看，玻璃不过是玻璃，既不多也不少——
>
#【清修】
「咦……？
　这、这是什么……」
>
# 那确实是玻璃板无疑，只是透出对面的景象，其中竟也映着青年的身影——并非那种『映出了窥视的自己』的拙劣修辞，而是刚才还站在玻璃板对面的筑宫的身影。
　在他惊愕的注视中，玻璃对面的青年也动了起来，精准重现了数秒前他绕到尽头的动作，然后消失。
　一种不安的感觉涌上心头。
>
#【清修】
「这是……刚才的我吗？」
>
#【司书】
「对。是你几十秒前的动作影像。这叫做『慢玻璃』。」
>
# ……到了这时，司书女史才终于解释。
　据她说，这是一种让光线极其缓慢透过的玻璃。细节的技术解释因术语繁杂便略去，总之，映在这上面的影像，即使本体消失，仍会以映像的形式留驻一段时间。
>
#【清修】
「原来如此……您还真带来了稀罕东西啊……」
>
# 筑宫虽姑且发出一声感叹，却总觉得没什么兴趣。
　这固然是件有趣之物，或许还是极珍贵的宝物，但对他而言，似乎并无太大意义。
>
#【清修】
（意义……意义吗？）
>
# 一股突然涌上心头的感慨，带着苦涩。对自己而言，真正有意义的事，究竟是什么呢？他忽然感到一阵空虚。虽说这慢玻璃于己无意义，但除此之外，又有什么是有意义的呢？
　一时泛起的好奇心，如阳光下的蚯蚓般瞬间干枯。再次涌上心头的，仍是那片朦胧的忧郁。
>
# 大概是因为这慢玻璃映出了数秒前的自己，让他意识到了『过去的自己』。
　如今已然失去的自己的过去。
　那又是怎样的呢？
　……想来，即使想起，也绝非什么好事。
>
# ——总之，不想再待在这里了——
　——想去不是这里的某个地方——
>
# 即使在旅笼的生活中已渐渐习惯、有时几乎遗忘，那份念想仍如沉渣般积在心底，偶尔会在不经意间泛起苦涩。就像此刻——司书望着沉浸于思绪中的筑宫的侧脸，若有所思地轻抿嘴唇。她虽不愿自傲，但本是打算让青年赏心悦目才展示这慢玻璃的，如今却看出它非但未能如他所愿，反倒将他推入了忧郁的沉滞之中。
　她向那如被忧郁咬住尾巴般的筑宫开口：
>
#【司书】
「你怎么了？
　那副眼神，可真是想得太深了——」
>
#【司书】
「这玩意儿，就那么不合你意吗？」
>
# 女史的指摘完全正确，此刻筑宫的目光，与临死前凝视最后之鸩的自杀者无异。
>
#【清修】
「倒也不是那样……」
>
# 他简短地应了一声，但那显然是拙劣的掩饰，无论怎样心情都无法晴朗。
　——忽然，这种『有人在一旁』的状况变得无比令人烦躁。无论对方是谁，即便是这位司书也一样。平日里这图书室古旧纸张的气味，总能让他放松身心，此刻却令他极度不安。若继续待下去，定会说出失礼的话。怀着这般危机感，筑宫连好好道别也无心，决定离开图书室。
>
# 女史似乎还想留他片刻，但青年还是断然离去。
　她透过慢玻璃目送他的背影。
>
#【司书】
「这样……那我不强留了。
　不过你啊，最好别太靠近那份忧郁。」
>
# 那忠告仿佛看透了他的心境，满是忧虑。但在筑宫听来，却只觉聒噪，像老妇的唠叨。他无言地离去。那离去的背影在慢玻璃中反复留存，司书只是默默看着。
>
# 而筑宫这边，因对关心自己的司书采取了那般态度，忧郁的心绪反而愈发浓重地扩散开来——恶性循环。青年百思不解自己为何陷入这忧郁的泥沼，却又毫无头绪，这更让他感到自己的窝囊。思绪周而复始，无止无尽——
>
