# ――呻吟声比生锈的滑轮更沉重地嘎吱作响，带着悲愤之色。砸在屋瓦上的小小拳头，每一处关节都塞满了绝望与焦躁。
 然而，无论这恸哭何其令人心痛，也无人侧耳、无人同情，更无人为她指出消除迷惘的道路。女人——法师独自一人跪在屋顶上，抽泣不止。泪与声被风撕扯成碎片。
>
# 不，即便有谁在场目睹，恐怕也没有任何人能理解她的绝望，更无治愈之法。
>
# 一味沉浸其中、近乎化为自身一部分的技艺与道路——其丧失的绝望之深，除当事人外谁能知晓？
 法师将身体投在屋瓦上，泪珠点点留痕，身旁放着琵琶。这把陈旧磨损、褪色的琵琶，一旦被法师抱在膝上，便能奏出仿佛天界乐人降临般的乐音——那不过是数日前的事。
>
# 而今——而今——
 纵使她倾注全身全灵的思念与祈愿，抑制着痛切的颤抖而拼命挥拨，甚至懊恼到在屋瓦上翻滚、如爪抓般恳求，灵感也不复返，旋律也不归来。法师的琵琶如墓石般沉默，没有对她说话的声音。
 弦与拨只余颤抖，不成声音――
>
#【法师】
「我想弹啊，像从前那样。
 所以，求你了，喂……！」
>
# 仿佛要将全身血肉、奔流的热血全部榨干般祈祷、恳求、挣扎。泪水刺痛，已看不清东西。唯有天空澄澈湛蓝，唯有霞雾洁白，广大屋顶之上，法师苦恼的模样显得无比渺小。
>
# 法师曾怀抱一丝期待：若在这屋顶上尝试，也许胸扉大开、凉风通透，或能取回些许琵琶之声？但愿望成空，毫无改变。
 在穿越天空的风中，她拼死地对着琵琶本身，或是将她旅途中所拜谒的种种神佛、精灵的容貌浮现在眼睑内，祈祷思念。
>
# 然而，并无应许愿望的迹象。在澄澈如透镜的气圈底层，与琵琶旋律割裂的孤独感愈发深重。法师终于拿起琵琶，高高举起——脸颊如被逼到绝境，危险地抽搐。
 她将如此珍视的生涯伴侣，任由激情驱策，砸向屋瓦——千钧一发的鼓动，在心中奇妙而规律地跳动。
 直冲天际的琵琶尖端，分毫不差地定住。
>
# 瞬，一瞬，又一瞬。
 绷紧的瞬间被拉长，然后法师——将琵琶——
 缓缓地、静静地放下。
 好不容易捱过那仿佛被过路神附体的激情，在将要砸碎可称自身一部分的琵琶的瞬间悬崖勒马。将琵琶放在熏黑的瓦片上时，心脏——此前诡异地平静的鼓动——爆发了。
>
#【法师】
「啊、呜……」
>
# 体内仿佛另一只凶暴野兽狂乱般的心悸，在法师放弃砸碎琵琶之后袭来，将她再次打入狂乱发作。
 她踉踉跄跄走下屋顶。
 即便屋顶茫漠如高原般广阔，也仍有边缘。若踏越，非鸟之身将直线坠落。之后若运气好被大河吞没，或撞上旅笼构筑物，化为血、肉、骨的污迹。
>
# 那一刻，她真正地如此期望。
 这般连琵琶也弹不了的没出息自己，索性全部交给坠落，之后怎样都无所谓——被这种自暴自弃的冲动从背后踢了出去。
>
#【法师】
「不行——不要那样……」
>
# 濒临疯狂的眼神，随着屋顶边缘临近、随着捕捉到下方令人目眩的广阔景象，渐渐恢复正气的神色。求生本能直击膀胱，几乎失禁。但顺着斜坡下行时速度加快，变成小跑，如今法师自己也控制不住了。
>
#【法师】
「噫……噫呀啊――」
>
# 可怕，恐怖，不想死，讨厌痛。可心脏仿佛从内侧拖拽着她，脚步不停。法师迸发出怪异且愈发凄惨的悲鸣，牙齿打颤，拼尽全身力气——
 拼尽全力，横向倒下。
 因为已无法靠自力停下奔跑，她以最后的赌注自行跌倒，从而让自己偏离奔向死亡的道路。
 果然——瓦片自上而下作响，瘦削的身体弹跳了两三次，停下了。那离屋顶边缘仅有毫厘之差。
 啪啦、啪啦，干燥的泥土和瓦片碎片从屋顶边缘掉落。
>
#【法师】
「……呼啊……」
>
# 摔倒的侧身、擦破的肘膝阵阵作痛。但疼痛是生的证明。法师吐出安心的气息，那气息立刻化为呜咽。
>
# ――自己在做什么啊。
>
# 无论多么痛苦，砸碎琵琶算什么？不过是迁怒，难看至极。
 无论多么没出息，投水自杀也毫无意义。
 她一边用袴腰蹭着瓦片，一边瘫坐着，远离边缘。片刻前的自暴自弃冲动已消失，对坠死的恐惧让心脏快要破裂。
>
# ……总之，将自己拖到不会坠落的地方，法师将额头抵在瓦上，哭倒了好一阵子。
 扬起沾满灰尘与泪痕的脸，眼神却如灵魂麻痹般空洞。起身的动作也孱弱得仿佛强风一吹便会轻易吹飞。
>
#【法师】
「我，是笨蛋……
 琵琶，已经弹不了了。
 也害怕死亡。」
>
# 声音痛切，仿佛淤青中透出的青黑色指甲之色。法师独自拭泪。
 有歌谣用尽手段责备忘却歌声的金丝雀，或安慰它、试图让它忆起。但失去歌声最觉寂寥的，是小鸟自身。法师亦然。她的苦恼，旁人——即便筑宫青年——也无法衡量。
 无论怎样因焦躁与绝望而翻滚，琵琶之声也不复返，也无法死去，在无人处出丑——这身子究竟有何价值？法师深深叹息。
>
#【法师】
「我……
 为什么，会在这里呢……」
>
# 眼角如被盐腌般刺痛，她拭泪，但手背也脏了，只让刺痛更甚。悲惨无底。法师试图回想起自己为何如此执着于琵琶的根源。
>
#【法师】
「是吗……
 我还什么都没找到呢。」
>
#【法师】
「那个人——
 最初让我听到琵琶的人。」
>
#【法师】
「那个人，直到最后一刻都在祈愿。
 哪怕一次也好，想听到『秘曲』。」
>
#【法师】
「他不甘心。不甘心没能遇到那曲子就死去。」
>
# 空洞的眼神中，光芒开始一点点恢复——但那并非迎着逆风决然挑战般的力量，而是如同被不治之症缠身的人，无论如何也要给未竟之事做个了结一般，充满着悲哀的决心。
>
#【法师】
「我也，完全没找到啊……
 琵琶不行，连死都怕。
 既然如此，至少——」
>
#【法师】
「那个人留下念想的，那支曲子。
 至少那个，我想找到――」
>
# 话语随风飘散，她站起身，迈出脚步。与其说是她自己的决心赋予了再次站立的力量，不如说她像是被死者的妄执缠住的人偶，以那样的步伐，法师从屋顶返回了旅笼。
>
#
 此后她怎样了？
 她本就不是喜好与人交往的女子。在旅笼大多数人的看来，她是个无足轻重的女人，连那作为唯一长处的琵琶，若非风雅之士，也不会主动竖起耳朵去听。
 更何况，会为她的苦恼费心的人更是没有，几乎无人会去一一挂念她的行踪。
>
# 因此，除了筑宫这位为数不多挂念琵琶法师的人之外，注意到她在那屋顶一幕之后便消失不见的人，一个也没有。
>
# 在水渠的景色中往来穿梭的旅笼客人与侍女们，从高处的回廊俯瞰下去，都只有豆粒大小，谁是谁、面目如何都分辨不清。
 即便如此，筑宫仍不得不寻找她的身影——尽管他知道这如同在马厩中满地的碎稻草里，去抓唯一一根混入的金针般希望渺茫。
>
#【清修】
「到底去哪儿了……」
>
# 低语声中，焦躁与疲惫如同受伤的树干渗出的露水般若隐若现。
 这也难怪。在这片广阔、连像样地图都没有的旅笼里，力所能及地问遍了、寻遍了，任谁都会如此。
 不仅如此，开始寻找之后，他曾两次险些在人迹罕至的区块中迷路走不出来。
 但筑宫仍然不顾自身地拼命寻找。
>
# ――青年注意到琵琶法师不见了踪影，这事本身倒是出乎意料地快——就在她从屋顶自杀未遂的那天傍晚。
>
# 『一定是因为自己愚钝而疏忽的话语，把法师逼到了绝境』——除此以外别无他想，筑宫这次开始逼迫自己。
 别人或许会安慰说他想太多了，但筑宫这个人，一旦是自己犯下的过失，比起挽回失败向前站起，更习惯一味躲进阴暗处持续自责。虽说比起没意识到过失而反复重犯，这姿态是更加可敬，但一个人背负也是有极限的。
 然而筑宫却将法师的失意与苦恼，全都归咎于自己的不周。
>
# 要是自己再多照顾她一点就好了。要是能再巧妙一点、再灵活一点就好了。
 诸如此类，比梅雨季节的长靴内部还要潮湿发霉地忧虑、痛苦，根本达不到『法师或许需要一点冷静时间』这种冷静的观点。
 在温室那场暴力骚动之后，没能追上法师，也成为青年自责的种子之一。分别后回到自己房间，他也一直咬着后悔的尾巴不放。
 几乎彻夜未眠，心想『应该去见见她』——不，就算见了，靠这根笨拙又愚蠢的舌头又能说出什么安慰的话？只会更伤她，不该去——内心的天平左右摇晃。等他终于决定出房间时，已是午后很晚了。
>
# 战战兢兢地去法师的小庵打听，却不见她的身影，那时他还没那么焦躁。温室、酒馆——还有其他她可能去的地方。
 可是挨个找了一遍也没找到，接着又去屋顶、大浴场，还是见不到。那时天色已晚，最后又回到小庵，但等呀等，也不见法师回来的迹象。
 没有主人的简陋小屋，只越发凸显荒废之色。一个人生火等待的虚无感无以言表，把细微的声响误认为是她的脚步声，一喜一忧。结果那天，法师没有回来。
>
# 那天没有，次日也没有，又次日也没有。
>
# 随着日子推移，筑宫的焦躁与疲劳日益加剧。像这样倚靠在回廊栏杆上时，稍不留神意识便要远去。更没有闲心打理仪容，嘴唇周围胡子拉碴，他用粗糙的手背擦着扎人的胡茬，叹息不已。
 能想到的地方都找遍了。
 即便如此仍未发现琵琶法师的踪迹，筑宫已因疲劳与不安而消耗殆尽，几乎要呕出血来。
 不只是不见人影。
>
#【侍女】
「这个嘛……帮不上忙真抱歉，我也没见到呢。」
>
#【侍女】
「不过啊……不是说法师大人本人的消息啦。」
>
# 厨房的侍女将筑宫搭话当作歇口气的借口，匆匆洗掉照看的糠桶里散发酸甜气味的米糠，压低声音凑近脸来：
>
#【侍女】
「我听到的可不是什么好话。
 你看，法师大人不是在酒馆被坏心肠的人纠缠过嘛。」
>
# 在顾忌周围的低语中，不祥的气息撩拨着筑宫的不安。
 「纠缠」二字可远不止如此。看来这位侍女有所耳闻——在温室里，他们险些被那群坏心肠（这评语可真够温和）的歹徒凌辱。
 那时靠大小姐威严的呵斥将他们赶走了，但如今似乎那帮无赖又掺和进来了。
>
#【侍女】
「听说在温室也闹了一场。
 当时好像被我们老板娘赶跑了，但那些家伙现在怀恨在心，反过来找法师大人，到处搜她呢。」
>
# 世上竟有如此心性扭曲腐烂之人。筑宫听后，危机感愈发强烈。
 下次若法师再被那些蠢货抓住，幸运到又遇上大小姐在场的巧合，恐怕不会再有第二次。
 而且，那类人的怀恨，再怎么保守地看，也容易预想到会采取令人作呕的形式――
 无论如何，必须抢在他们之前找到法师——筑宫几乎发狂般地焦急。
>
# 可再急，光靠他一个人也想不出对策，在这种地方束手无策也只是浪费时间。
>
#【清修】
（能想到的地方都找遍了，
 可这地方太大了。）
>
#【清修】
（要是她躲到没什么人去的地方，
 根本没法找。）
>
# 可恼的是，即便筑宫找不到，也毫无保证那帮无赖也找不到。
>
#【清修】
（只靠我一个人果然到极限了……
 自己的烂摊子不能自己收拾干净，真丢人。）
>
# 他虽自知不应轻易求助他人，但受害的并非筑宫自身而是琵琶法师，因此也容不得他一个人慢悠悠地撑着。
 即使要暴露自己的不中用，也应该求助的力量——此时浮现在筑宫脑海的，有一个人，不，两个人。
 其中之一自然是大小姐，她与此事本就有些关联，更重要的是她掌握旅笼的管理之权。
>
# 而另一人，是那位戴着破裂般般若面具的女人——那个摆渡人。
 船女是个怪人，有不可捉摸之处，但不知为何，筑宫觉得她对自己怀有某种近乎情谊的东西。而且，与大小姐不同，她似乎还涉足这旅笼的深层部分。
 或许可以找她商量一下？
>
# ――最终，筑宫在大小姐和船女之间犹豫了一番，决定去找那个戴破裂般若面具的女人。
 而且，可能性虽低，但找了这么久都不见踪影，也许琵琶法师已经离开了旅笼。
 若是那样，她的消息船女应该知道。
>
# 如此想着，筑宫朝摆渡人用于系着小舟的方位走去。与此同时，他也暗自祈祷自己的猜想落空。
 若法师真的离开了旅笼。
 那就意味着，她连告别都不曾对自己说过。
>
