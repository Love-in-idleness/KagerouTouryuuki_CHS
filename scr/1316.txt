# ……与筑宫和法师的交情蒙上昏暗阴影的几乎同一时期，旅笼开始频发怪异。
 据客人和侍女们口耳相传，那怪异的姿态是一群奇怪的小人。
>
# 例如深夜，某位客人被异梦魇住，寝汗令人不适，被褥感觉异常沉重，正欲跳起。岂料被子仿佛用胶固定一般纹丝不动，不仅如此，室内还充满无数气息，耳畔远近响着窃窃私语。说是声音，却细微如针尖划过纸面，听不清在说什么。大抵像是只有小虫大小的东西，用其小小的喉咙所能发出的最大音量在互相叫嚷。
>
# 不知发生了何事，勉强还能活动的头在枕上转动，便见长明灯或纸拉门透来的微光中，浮现出小指大小的、隐约是人形的轮廓——但细微的面容、装束却无法分辨。室内本就昏暗，而那东西全身漆黑如蘸了墨，像是黑色的芸豆荚上安了细小的手足——单个就已令人毛骨悚然，如今却在房间的家具、坐垫上，无论何处都密密麻麻地涌出无数，数不胜数。
>
# 这群异样的小人，有的爬上桌子滚落下来，有的被榻榻米边缘绊倒摔个趔趄，有的在烟灰缸里滚得满身灰——放肆至极，却偏偏连一道影子都不落在地板上，愈发凸显其妖异之相。
>
# 光是这般在室内各自跳梁跋扈，就已经是足以夺人心神的异景，而很快小人们的行动中又产生了一股意志——在客人被封住的被褥周围围成一圈，步步缩小包围圈。
>
# 想逃却逃不掉，被褥沉重，手脚麻痹。然而小人的队列如今已明确朝向客人的脸，排成行列，如同蚂蚁军团突入敌方巢穴般，扎实地朝客人的脸、朝口中逼近。
 它们是想钻进体内——！？
 大惊之下闭上嘴，但鼻孔却是张开的——这便是人体的构造。察觉嘴巴行不通，小人们的行军矛头便转向鼻孔，黑色的手臂攀上鼻孔边缘，五官不清的脑袋倒着拧将进来――
>
# 大多数客人到了这一步，便再也忍不住发出尖叫。那因恐惧而起的凄厉之声，震得纸拉门的纸颤动，连电灯伞内侧积攒的灰尘都扬了起来，那些企图从鼻孔侵入的小人、列队待命的也一样，全被吹飞，最终连同一楼层的其他客人都被吵醒。
 被搅了睡眠的客人们赶来时，怪异已不留痕迹地消失，只看到房间角落里蜷成胎儿姿势、瑟瑟发抖的客人。
>
# 起初，听到这事的大多数客人的反应是：大概是做了个梦吧，觉得扰人清静，或是一笑了之。然而可怜的受害者数量逐渐增加，昨天还在笑话别人的人，当夜就被同样的怪异袭扰，而且一夜之间多处同时发生的情况也多了起来，再也不能轻率对待。
>
# 其中也有刚强的客人，非但没有惊慌失措，反而以胆力压住恐惧，一声气合从脐下丹田挣开梦魇，对着摸到枕边的一个小人，像拍打纠缠的蚊子一般一掌拍了下去。真是豪迈之人，但似乎没考虑过后果。
 确实拍扁了，却没有手感，狐疑地查看掌心，只觉滑腻。在夜色中也能看出黑乎乎的濡湿，还以为是自己手掌的皮被拍裂了，一惊——并非如此。没有疼痛，粘在掌上的，是墨汁。
 榻榻米上也留下墨渍，正纳闷这是什么把戏的下一瞬间――
>
#
――啪嚓――
>
#
 如同甩湿抹布般的声音响彻房间，其他四处乱窜的小人一齐失去形态，崩溃消失，留下的只有墨渍、墨渍、墨渍，一片漆黑，遍布榻榻米。
 ……哎呀呀，清洗起来可费了大事，最终那间房间不得不全部更换榻榻米。
>
# 但是，仅仅是睡眠被打扰或者房间被墨渍弄脏，虽然大为麻烦，却还算好的。
 为何？请回想一下那群小人的本来目的。没错，它们是想趁人熟睡之机从口鼻等孔窍钻入体内。不过多数都在途中被发现，它们的企图未能得逞。
>
# 然而，终于出现了被附身的客人。受害者是同住一房的姐妹俩中的姐姐——顺便一提，她们所住的房间，据说是因为想转变心情，刚刚换过来的。而那个房间，正是某日筑宫青年和琵琶法师从那地下酒馆的流氓手中逃脱之后藏身的那间洋室。这或许是一种暗号吧。
>
# 总之，半夜妹妹因睡得不舒服而醒来，缘由是并排铺被的姐姐发出的奇怪呻吟。她揉着惺忪睡眼，拧亮枕边的床头灯开关，恰好看见黑色的小人钻入姐姐半张的嘴唇之间——就在她注视的当儿，那轮廓模糊的腿还在蹬动，随后完全没入口中。妹妹听说过这半夜怪异的传闻：小人本应成群出现，但房间里却看不到其余的身影——难道是因为自己醒得太晚，它们已经几乎都进了姐姐的身体里？妹妹正悚然之际，姐姐的喉咙『咕咚』一声，做了一个吞咽的动作，极其令人厌恶。妹妹再也受不了，当场吓晕过去。
>
# 次日清晨醒来，姐姐已经起身。妹妹立刻想起半夜的情景，扑过去抓住姐姐。但姐姐却极为平静，和睡前毫无两样。妹妹战战兢兢地提起昨夜的事，姐姐却似乎全无记忆。妹妹见姐姐并无异常，暂且放下心来，告诉自己那一定是梦或幻觉之类。话到此处本该结束——却并未结束。
>
# 话说回来，这并非什么容易看出来的妖异变化——比如因为墨色的小人而全身发黑，或者嘴里不停地吐出墨汁，把周围变成墨池之类。
>
# 从那天午后开始，姐姐的举止中开始出现奇怪的部分。
 这位女性，学生时代学过钢琴——但也并非跟了了不起的老师、进行过刻苦修行那种程度。只是放学后的课外练习，虽然也有过一些辛苦，但大体上是轻松的尝试，并没有持续很久。既没有闪耀的才华，本人也没有多少热情，想学也不过是麻疹般一时的冲动，放弃之后也没有耿耿于怀，倒是清爽了。
>
# 然而，钢琴热却突然复燃。午饭后她显得异常坐立不安，妹妹这才开始觉得可疑。她想弹钢琴——不，是非弹不可——在旅笼里四处奔走，当在被弃置的区块里发现一架立式钢琴的游戏室时，她已经气喘吁吁，爬也似地扑向钢琴，开始敲击黑白琴键。但早已被遗忘的钢琴音律失调，而同样被姐姐长久冷落的钢琴技巧也已经生锈衰退到连运指都不利索，什么音阶旋律全然不成调，那如同腐坏味噌般的演奏，令随后追来的妹妹捂着耳朵在地板上打滚。
>
# 之后便是一场大乱。无论怎么安抚劝说，姐姐都不肯离开钢琴，非但如此，还咬住试图阻止她的妹妹的手，披头散发地一头撞过来。她废寝忘食，隔绝外界，仿佛要弥补离开钢琴之后的时光一般，一心不乱——不，是呈现出超越疯狂的样貌。连续整整三天三夜，她不停地、乱七八糟地独奏，最终耗尽体力，翻着白眼、口吐白沫，向后倒下。
>
# ……事后，充当医生角色的侍女们用尽手段，妹妹也持续献身的护理，姐姐终于恢复了意识。但那时，钢琴的狂乱热已如谎言般消失，她本人也茫然自失，只吐露道：
『那时候，我就是无论如何都想重新开始弹钢琴，想继续下去。当初放弃的时候，其实也不喜欢那样半途而废，要是可能的话，真想一辈子投入进去……那种心情涌了上来。现在，那种疯狂的冲动真的一丁点也没有了。』
 说完便疲惫地将头埋进枕头。
>
# 她为何如此狂乱？好事儿的侍女们煞有介事地解释说：那间游戏室的钢琴里，附着了壮志未酬而夭折的钢琴家的遗恨，为了让人继承其意志而诱惑人等等。但妹妹却隐约察觉到了。
>
# 是那夜钻进睡着的姐姐体内附身的黑色小人团伙，将疯狂植入了姐姐体内――
>
# 而以此对姐妹为开端，同样被狂热爱袭扰的人开始陆续出现。
 被附身者不分老幼男女，但其行为有一个共同点：但凡曾经接触过——哪怕只是短暂的时期——某种技艺或竞技之类，那股热情与眷恋便会重燃，排除其他一切，陷入疯狂的投入。
 然后，持续数日——即直到被附身者的体力极限——埋头之后昏倒。事后本人也不明白自己为何会如此疯狂。这一点也是相同的。但最大的谜团是：带来这种疯狂之疾的黑色小人，究竟为何出现，又为何要附身于人……
>
