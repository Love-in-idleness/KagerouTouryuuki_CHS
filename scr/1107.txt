# ――翌日清晨――
 独自在房中用完早餐，按理说味道应与往常一样鲜美，却觉得索然寡味，仿佛用假材料仿制出的形似之物。
 不过，要说真有侍女闲到对筑宫搞这种恶作剧，也不太可能，终究只是心境使然罢了。
>
# 『朝旭发善思』——虽听过类似格言，但实际刚起床时血脉不畅、头脑迟钝，思绪并不灵光。筑宫首先想到的是：对，去找摆渡人吧。但这也不是他自发的灵光，而是昨夜小姐所暗示的。
 ……也罢，或许正因为只惦着这事，舌头才没能品出早餐的滋味。
>
# 原本将自己带到此地的，就是那位船女。无论继续逗留一阵，还是即刻启程，都应该去见见她，打声招呼才是。
>
# 总之，给银怀表上了发条后，筑宫出门寻找船女。然而她的行踪不定，载客在水路各处穿梭。青年问了问侍女。
>
#【侍女】
「这个嘛……今天没见到呢。」
>
# 如此回答。也罢，想着总能在船埠头或伸向大河的栈桥遇见，便未深想，信步走去。
>
# 不料扑了个空，连水面上吹过的微风都显得寂寥。即便如此，筑宫仍像老电影里那样悠然——并非刻意模仿——在岸边坐下，望着缓慢拍岸的涟漪等待。等了不知多久，身体忽然大幅摇晃，险些一头栽进水里。
>
# 果然还是昨夜难以入眠的后遗症。他怃然四顾，看有没有人瞧见自己这蠢相，所幸无人注意，但也不见船女的身影。
>
# 虽想过今日就此作罢，但转念一想：正是因为意志如此薄弱才会差点落水。他轻拍脸颊，重振精神，决定再在旅笼里找一遍，遂站起身来。
>
# 于是整个上午，筑宫的身影在旅笼各处的水渠边频繁出现，如觅食的水鸟般忙碌奔走，却终究未能遇见摆渡人的小舟。
>
# 或许这也是缘分。他在水渠边坐下，脱下拖鞋与袜子，将疲惫的双足浸入水流，叹了口气。
 自认已颇习惯步行，但唯独今天，身体各处血脉淤滞，肌肉残留钝痛。
 探寻原因时，筑宫顿时面红耳赤。
>
# 这不是明摆着吗。
 昨夜过度使用了不惯用的肌肉。
 自问到底怎么回事既愚蠢又难堪——自己与小姐共度了怎样的一夜啊。他正再次觉得今天与船女恐难见面，却还是重新穿上拖鞋，继续寻找。
>
# 或许自己变得固执了，但固执也好。
 夜里饮酒、耽于女色，若回想白天做了什么，与其草草放弃找人、以『只是等着天黑』收场，不如略带执拗地四处走动，好歹对老天爷也有个交代。况且，如此劳累身体，至少今夜能睡个好觉。
>
# 抱着『既然如此，索性找到天黑』的荒唐决心，他回到作为起点的船埠头时，却不禁有些扫兴。
>
#【船女】
「哎呀老爷……您怎么跑得气喘吁吁的。」
>
#【船女】
「先润润喉，来一口如何？」
>
# ……不知何时错过的船女已把小舟划到船埠头，而且心情甚好，朝青年晃了晃她惯用的葫芦。
 看来她从白天起就开怀畅饮。瞧见这位正苦苦寻找摆渡人与刚才还以此自戒的组合——『酒与女人』——重叠，筑宫的表情变得颇为微妙。
>
