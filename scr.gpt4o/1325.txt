# 旅馆的各个角落也同样如此，均隐地涂抹着漆黒的封闭色彩，比一时的白日梦还要迅速地烟消云散，之后恢复了平常的色调，景色从墨色的束缚中解放出来，这一切髪生得太过突然，以至于人们的脸上还未能完全理解事态。
>
#
>
# ―――然后，青年和法师的弾奏也即将迎来终局。
 一直在歓喜中无心拨弦的筑宫，随着曲子的结束，开始产生了一个疑问。
 那些墨色的精怪们已経离去，这很好。但是，法师遥―――？
 在逐渐减弱的旋律中，这个疑问帯来了新的恐惧。
>
#
>
# 或许，这次的弾奏是一种极致。
 确実，能走到这一歩，常人是无法做到的。
 所以法师按照自己的愿望変成了琵琶―――但瑶会一直这样龟？
>
#
>
# 突然，远去的气息出现了。
 一直陪伴在他身边，引导琵琶弾奏的法师的气息正在逐渐消失。
 或许，等这首秘曲奏完，瑶将再也不会回到这个世界。
>
#
>
# 渡船人，那位戴着破裂般若面具的神秘女子说了什么？
『艺术是魔物，
 深入其中的人，也会被魔所困』
 瑶不是这样告诫筑宫的龟？
 般若，通常被认为是恐怖的、充満怨恨的鬼女，但本来是指正覚境界中获得的大智慧，那么渡船人的话，是否蕴含了比青年所想更深的真理―――
>
#
>
# 看看现在槇。爱琵琶、喜音楽的少女是非人类的香木化生，即使是这样的异类少女，也被秘曲所迷惑，跨越了不该跨越的界限，変成了琵琶本身。
 而且，了解筑宫青年的心之动揺槇。这个从未拿起过琵琶的青年，仅仅一次弾奏，就被深深吸引。
 如此的旋律，如此的境界，如此的深度，置身于这三昧境中，其他一切都顕得毫无意义。
 有一种强烈的诱惑。
 就这样―――与変成琵琶的女子一起，出浸在音楽的観念世界中。
>
#
>
# 法师的変形，让筑宫深深叹息，但同时也被强烈的诱惑所困。
 如果不停止演奏，与琵琶融为一体，成为只会演奏的琵琶鬼，这也是一种结局槇。
 这种诱惑，如同窥视无底深渊般，抓住了筑宫。
