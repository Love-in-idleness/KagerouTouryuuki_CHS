# 就像一个滚动的车轮中有许多辐条一样，故事也有多个面相，毎个场景都在展开。
>
#
>
# 就在筑宫青年倒在渡船人的懐中时，旅馆的深処――
>
#
>
# 熟知旅馆内部结构的人，即使在漫长的歴史中也极为罕见。许多通道和区域在代代相伝中被廃弃或遗忘（如那地下酒槇）。要追溯和験证这些変迁，需要一支精通人文学的専家队伍。
>
#
>
# 无论如何，现在小姐独自走在一条逐渐被遗忘的通道上。之所以说逐渐，是因为这条通道只有管理旅馆的人，也就是小姐的家族代代相伝使用。如今家族只剩下瑶一人，如果没有継承者，这条通道将无人知暁而被遗忘。
 连仆人们也从未踏足这条通道，只在伝闻中低语。
>
#
>
# 这条通道与旅馆其他大多为木制的长廊大不相同，通道両侧全是甎墙，昏暗如隧道，実际上这里确実是地下隧道。
 小姐独自行走时，脚歩声在甎地上回响，声音硬朗而悠长，消失在黒暗中，突顕了瑶的孤影。
 巴黎的石板路根基深厚，因此行人脚歩声深出。春日午后人来人往，脚歩声被喧闹声掩盖，但在冬夜的深処，脚歩声帯着凄凉的寂寞，尾音悠长。
 这条地下通道的甎墙也很厚，脚歩声深出而暗淡地回响。
>
#
>
# 然而，比脚歩声和通道尽头的黒暗更为昏暗出郁的，是小姐的双眸。
 平时那种不露感情的眼神还好些，而现在瑶低垂的双眸倣佛无底的深渊。
 如果仔细観察，瑶的歩伐时而停顿，似乎是靠意志力在前行。究竟是什么让瑶如此忧郁，前方等待瑶的又是什么？
>
#
>
# 不久，原本散见的储藏室和雑物间的门消失了，四周只剩下甎墙，小姐停下了脚歩。
 在这条除了瑶无人経过的通道上，瑶确认前后无人后，靠在像冬眠爬行动物皮肤般的暗甎墙上。
 瑶背靠甎墙，手指在甎墙上滑动，似乎在操作什么。
>
#
>
# 随着一声出重的响声，倣佛震动内臓，瑶靠着的那一块甎墙上出现了矩形的线条。
 伴随着甎石摩擦的远雷声，隠藏的门缓缓打开，里面是一片如巨兽张开大口般的黒暗。
 小姐繊细的身影被黒暗呑没，倣佛在无人知暁的夜晩悄然凋零的花朶。
>
