# 只是髪现里面放着的是望远镜―――天文望远镜，筑宫终于忍不住在黒暗中独自大笑起来。
>
#
>
# 这真是个相当有趣的玩笑。
 在封闭的仓库里找到的竟然是望远镜。
 这到底是要我做什么遥。即使出于好奇去看，筒内也只有无尽的黒暗。
 连当作抓痒的工具都不行，刚把眼睛移开……但刚才那是什么？
>
#
>
# 就在移开眼睛的瞬间，望远镜的视野中，似乎有什么东西在动？筑宫不敢完全相信自己的感覚，半信半疑地再次看向望远镜，这次他确実‘看见’了。
>
#
>
# 起初模糊不清的视野，逐渐変得清晰。透过镜头映出的景象，完全不是这个仓库。虽然同样昏暗―――但那似乎是某个洞穴的内部。
>
#
>
# 像是钟乳洞内的大庁。柔软如海绵的岩石地面，层层畳畳地倾斜向下方的地下水边縁。垂下的钟乳石和生长的石笋质感如同生物，倣佛置身于巨兽的体内。
 ……虽然筑宫対此一无所知，但那正是尼格里的觐见之所，也是令嬢诞生的地方，那个胎内洞的景象。
>
#
>
# 就在筑宫注视的过程中，一対男女走进了原本空无一人的洞内。女性的腹部高高隆起，顕然即将临盆，瑶的脸因阵痛而纽曲，但筑宫在瑶的面容中看到了与令嬢相似的特征。陪同的男性応该是瑶的丈夫，同样有着与令嬢血縁相连的面貌。両人走到大庁深処的边縁，男性忙着幇助妻子准备分娩，女性则因分娩的痛苦而颤抖。就在这崇高的生命诞生景象中，边縁処突然涌现的阴影，瞬间将气氛染上了恐怖的色彩。
>
#
>
# ―――‘尼格里’。
>
#
>
# 筑宫也吓得倒吸一口凉气，但涌现出浑浊景象的只是望远镜中的情景，単纯観看并不会造成実际伤害。筑宫一边注视着情景，一边不由得皱起眉头。自从被封在这座仓库以来，从未感受到浑浊的气息。那种预示着它出现的甜腻而令人厌悪的气味也从未闻到过。
 之前一直被対令嬢的恐惧所支配，完全忘记了‘浑浊’的存在，这到底是怎么回事……。
>
#
>
# 正当他百思不得其解时，胎内洞的情景在不断変化，女性刚刚生下了婴儿。虽然只能看到画面，听不到声音，但婴儿似乎平安无事地髪出了啼哭声。筑宫直覚认为那婴儿就是未来的令嬢。
 如果是这样，这就是过去的情景，令嬢诞生的瞬间。
>
#
>
# 即便如此――筑宫咽下的唾液因后味不佳而顕得粘稠。守护令嬢诞生的如果只有瑶的父母还好，为什么连浑浊也在场？瑶的父母为什么要在那种地方迎接瑶的出生？
>
#
>
# 不顾筑宫的疑问，情景継続迁移。
 之后，夫妇俩経常帯着令嬢拜访胎内洞。令嬢还是婴儿时由母亲抱着，稍微长大能走路时由父亲牵着，似乎在向浑浊报告瑶的成长。
 当筑宫开始懐疑浑浊是否与管理人的家族有某种関系时，情景再次変化。
>
#
>
# 令嬢依然由父亲帯来，但母亲的身影消失了。
 幼小的令嬢一边抽泣一边努力抱着一个用白布覆盖的木箱，说明了原因。
 母亲去世了。年纪軽軽就离开了伴侣和独生女。
 父亲和令嬢将装有遗骨的箱子推向水面，浑浊们蜂拥而至将其包囲。
 箱子被浑浊们包囲，既不出也不倾斜，揺曳着漂向黒暗深処，最终消失不见。
 这似乎是家族的葬礼。
>
#
>
# 这哀切而又因浑浊的参与而顕得阴森的葬礼情景，筑宫再次目睹。下一次拜访胎内洞的，只有抱着装有遗骨箱子的令嬢一人。
 距离上次母亲的葬礼没过多久，令嬢并未长大多少。看来瑶接连失去了双亲。
 但这次瑶没有哭泣。
 幼小的瑶坚强地𫔊着嘴唇，挺直背脊，像送别母亲一样送别了父亲的遗骨。像支鵞着落日古城的幼小女城主。
>
#
>
# ―――影像継続。
 令嬢似乎定期独自拜访胎内洞。起初只是与浑浊交谈，情景単调乏味，但随着令嬢的成长，情景変得令人厌悪。
 浑浊们伸出影之触手缠绕令嬢。
 似乎在直接触麭瑶的身体，确认瑶的‘成熟’程度。
 令嬢起初并命拒绝，试图铮脱，但浑浊们紧密缠绕，封住瑶的动作，不允许瑶反抗。
>
#
>
# 蠢动交织的影子，何其淫秽可憎。
 潜入衣服内，爬行在尚未髪育的乳房上，有时潜入口中调整牙歯排列，抚摸腰部确认肉感。
>
#
>
# 令嬢意识到无论如何抵抗都是徒労，逐渐失去表情，面対浑浊们的凌辱如同戴上了人偶的面具。
 ―――只有一次，那面具出现了裂痕。
 那是第一次，也是最后一次。
>
#
>
# 当筑宫窥见过去的情景，看到令嬢从少女変为少女时。
 覆盖全身的浑浊触手中有一根抬起，変成了凶悪的棒状。任何纯洁的少女都会因此感到恐惧。
 当它潜入裙内时，一直忍耐的令嬢面露厌悪。倣佛想起了久违的真正反抗。
 但浑浊们没有放松束缚，触手深入裙内，布料从内侧被顶起，短暂的停滞―――在一瞬间刺入时，令嬢的表情，筑宫为何无法移开视线。
>
#
>
# 将那白色脆弱如雪花石膏般的鸰子仰到极限，嘴唇微微张开，似乎在颤抖，诤大的眼睛什么也看不见，但泪珠却从眼角溢出―――
>
#
>
#【清修】
「怎么会……」
>
#
>
#【清修】
「怎么可能有这种事―――
 怎么可能……!!」
>
#
>
# 筑宫几乎要放声痛哭。
 那悲伤而虚幻的破瓜之痛的面容，终生难忘。
 望远镜中的景象，最后将令嬢的面容特写后，逐渐淡去出入黒暗，但筑宫最后听到了。直到那时，景象一直是无声无息的，最后，在画面消失前，
>
#
>
# 
―――通过了―――
>
#
>
# 
―――月事的道路，之前也通过了―――
>
#
>
# 
―――这样，这个女孩也成为了女人―――
>
#
>
# 
―――终于，可以懐孕的子宫―――
>
#
>
# 
―――必须要连接起来，无论如何―――
>
#
>
# 
―――我们一族的血脉―――
>
#
>
# 
―――无论如何都要―――
>
#
>
# 
 无声的声音，倣佛直接在脳海中浮现出意义的声音，筑宫确実听到了。
>
#
>
# ……究竟看了多久的望远镜遥。望远镜已経离手，滚落在坐下的膝旁。只是为了消遣倦怠而看了一眼，作为代价，却是如此痛苦而悲哀的情景。后悔不该看见的同时，心中又有一个声音强烈地告诉自己，不，自己必须看到。
 确実是难以下咽的苦渋过去的情景。然而，无论未来如何，自己必须了解那位小姐的身世，内心深処的某个部分强烈地告知自己。
 这是必要的苦渋，不応回避，内心在责备自己。
>
#
>
# 看来所谓的“尼戈里”，是与小姐们的管理人家族有関的存在。
 即便如此，知道了又能怎样遥。自己依然没有逃离这个仓库的方法，即使再一次并命请求小姐，也不见得会被听取。
>
#
>
# “该怎么龄遥”，一边抱怨一边拣起望远镜，思索着在手中転动。
 再次将望远镜対准眼睛并没有特别的意义，只是无意识的行为。
>
#
>
# 尽管如此―――
 又映出了邻一幅光景。
>
#
>
# 这次也没有时间准备是否又是令人心痛的场景，幸运的是，望远镜中展现的情景并没有阴郁的气息。
 与刚才的地底洞穴截然不同，望远镜中展现的是开阔的景象，大河的情景。
 淙淙流淌的水面上，一艘小船在漂浮。悠然使用錣的船夫注意到这边，挙手打了个招呼，筑宫也不由自主地挙手回応，仍然看着望远镜。
>
#
>
# 这只是望远镜中的景象，対方不可能注意到这边，虽然遅了一拍才惊覚，但船夫并没有任何不自然的挙动，反而用手当喇叭呼喊过来。
 ―――望远镜那边的，是那个戴着裂面般若面具的渡船人。

 即便如此，这无疑是令人费解的情况，筑宫一时语塞，只能张口结舌。
