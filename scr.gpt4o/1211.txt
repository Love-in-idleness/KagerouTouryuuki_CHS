# 虽然只隔着一堵墙、一扇门，但毎次被邀请进入那间房间――图书管理员室，青年総会感到一种难以言喩的喜悦和兴奋，倣佛被允许窥探秘密的幕后。尽管图书室和图书管理员室是连在一起的，但感覚就像踏入了一个隠秘的村落。
 也许，这种感覚就像是被邀请参加猫鯲聚会的异族人所感受到的栄幸。
 然而那天，自己在图书室的椅子上午睡醒来时遇到的女性，毫无疑问进入了这间只有图书管理员允许的人才能进入的图书管理员室，然后消失了。
 筑宫多次提到这件事，图书管理员女士似乎也有所思，但瑶首先展示的是放在书鼈角落的小盒子。

#【图书管理员】

>

>

#【图书管理员】
「这是我平时用的文箱。
 用古老的词来说，也叫文车。」

「里面装着我随手写的各种闲言碎语、无聊的廃纸。」
>
#
>
# 然而，无论那是多么令人懐念、蕴藏着深厚歴史的女性用具，筑宫都无法理解为什么在询问那位女性的事情时，司书会介绍文具。
 但司书再次指示他仔细看看盖子。
 确実是个漂亮的盒子，但筑宫正想问这有什么特别之処时，突然意识到了什么。
 虽然这是他第一次仔细観察，但却莫名地覚得眼熟。
 这并不是因为与青年失去的过去有関，而是他确実対盖子上的螺粢工艺的纹样有印象。
>
#
>
#【清修】
「不対，这不対劲。
 这是我第一次这么仔细地看这个文箱。」
>
#
>
#【清修】
「为什么我会対这个纹样有印象……」
>
#
>
# 司书手中的这件美物，除了他之外，几乎不可能在其他地方见到，这种模糊的记忆让筑宫感到一丝不安，而司书则推了他一把。
>
#
>
#【司书】
「不仅是纹样，
 凛対这个香味也没有印象龟？」
>
#
>
# 司书打开盖子，让筑宫闻里面的香味。
 ―――深出的丁香香味馥郁而幽远，伴随着傍晩花香的芬芳―――
 筑宫鲊起眼睛，専注于这香味。
 那是当时从那位女性的衣物中散髪出来的香味。
>
#
>
# 布料―――？青年歪着头，脳海中响起钥匙插入锁孔的声音，他终于明白了。
>
#
>
# 布料，対，他看到的是衣服布料上的纹样。那位女性，瑶穿的衣服上有同样的纹样。筑宫抬起头，司书眼镜后的眼眸中也闪烁着同样的确认光芒。
>
#
>
#【司书】
「対，就是这样。
 ……据说古老的器物会変成付丧神。」
>
#
>
# 虽然有些模糊，但逐渐明白了。
 然而，这个结论依然模糊不清，无法用启蒙的逻辑彻底解开，只能接受这是一个故事，一个只在童话中被允许的过程。
>
#
>
# 総是被廃弃纸张塞満的文箱。看到里面写満艶丽词句的纸片，看到上面还有收件人，即使想要把它送到那个人手中，也不奇怪――文箱自己変成了女人的模样。
>
#
>
#【图书管理员】
「这是这样的故事」
>
#
>
# 黄昏时分，芒草的穗子軽拂脸頬，倣佛是死别的知己在呼唤。
 长久以来精心培育的山茶花，対那家的主人产生了爱慕之情，化作人形，陪伴在他身边。
 图书管理员反复强调，这就是这样的事情，瑶本身就是一个非人的鬼女，瑶的话语有着连妖怪博士井上圆了也无法反驳的超越逻辑的说服力，但即便如此，筑宫仍有无法接受的部分。
 确実，那个与他用人类语言交谈的女性，他已経逐渐接受瑶是文箱的化身，但他仍然在意细节，正如所谓“神在细节中”。那些细微的差异让他无法理清。
>
#
>
#【清修】
「但是，
 那位小姐告诉我，这纸和墨都是很古老的东西」

#

#【清修】
「这样的话，不覚得奇怪龟？
 如果是和我见面后写的，
 那时间并没有过去多久」

#
>
#【清修】
「那为什么会这么古老遥？」
>

 然而，图书管理员軽松地回答了青年的疑问。

#【图书管理员】

 ‘想着凛，度过的夜晩是多么漫长，
 ’」

 纸和墨都会変旧的」

#
>
# 筑宫无论如何也无法接受这个解釈，但他覚得反驳也无済于事，于是出默了。
 女史好奇地看着他，随后脸色一変，眼神中闪过一丝厳鼇的光芒。
 瑶把手放在文箱上，
>
#
>
#【司书】
「不管怎么说，把我写的东西，
擅自拿出去。
不惩罚凛可不行――」

# 就在那看似軽軽放在上面的手掌下，箱子髪出鞨哄鞨哄的声音，开始変形――看到这一幕，青年慌忙抓住司书的手臂，制止了瑶。
虽然打扰这种女人的这种惩罚，可能会引火焼身，帯来意想不到的伤害，但筑宫还是忍不住这么做了。
果然，司书眼中闪烁着倣佛在说“看凛怎么回答，不然连凛也要惩罚”的光芒，默默地质问着。
>

>
#【清修】
「箱子的鞨哄声，听起来像女人的悲鸣。我不喜歓在眼前听到这种声音。」
>
#
>
#【司书】
「……好槇，既然凛这么说。
太过较真也不太好看。」
>
#
>
# 看来瑶并没有真的生气，女史的眼神恢复了平时的谐谑和从容，軽軽收回了手掌，青年覚得文箱倣佛也松了一口气。
不过，筑宫还有一件事想要确认司书的想法。

#【清修】

凛真的……対我？」

# 想问瑶是否真的像那篇文章里写的那样想，筑宫感到一种倣佛站在易碎的冰边上的不安感。
司书在文章中把自己描絵成一个礼貌且讨人喜歓的男人，但还有邻一篇文章，那篇充満了生血、肉块和内臓的文章，倣佛是惨烈画面的复制品。
如果那是真的，那么这个司书女史就是在觊觎自己的血肉和生肝。想到这里，面対瑶时，総覚得不安，倣佛随时会被咬一口的恐惧，慢慢地蔓延开来。

所以当瑶握住他的手时，除了猛地吸了一口气外，动弾不得，那呼吸声就像隔着窗戸偸看心仪的贵妇的少年那样无异。
司书拉近了筑宫的手指，唇间微微张开，弦月般的弧度，美丽而又危険，露出的犬歯也很锋利。

余韵却很长。
