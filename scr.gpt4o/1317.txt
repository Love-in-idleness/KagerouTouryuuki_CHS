# 黒色小人的跳梁仍在継続，客人们被其困扰不堪，抱怨如同砾般向旅馆的管理者、小姐和幇工们袭来。
 旅馆自古以来就有各种怪异伝说，即使现在遇到这些也不稀奇。不过这些怪异大多无伤大雅，遇到的人事后也只是当作谈资，客人与怪异也因此得以共存。
 然而，这些小人却是前所未有的存在，造成的损害也相当厳重。被其困扰的人即使恢复了理智，也会因耗尽体力而长期卧床休养。
>
#
>
# 小姐们无法再袖手旁観，尽力尝试各种方法来镇圧和駆逐小人，但伝说中的追傩仪式和魔除符咒都毫无效果，毕竟根本不清楚这些小人是因何而来。
 旅馆方面也并非荏苒无所作为，但能采取的措施也不过是将客人的房间调换到其他地方。
>
#
>
# 経过多次受害后才髪现，小人只出现在沿水路的房间，离水路较远或楼上的房间则没有客人见过小人。
>
#
>
# 却说―――
 黒色小人的怪异成为话题的俎上，无论是在游戯室的四方山话中，还是在走廊上停歩闲聊中，几乎无処不在。然而，有一个人却被与这些怪异并列谈论。
>
#
>
# ―――琵琶法师―――
>
#
>
# 瑶的庵也在水路旁，但据说在瑶的庵及其周囲从未出现过小人。
 原本就很少有人拜访瑶，住客和人流也稀少，尽管如此，谣言却如同在石缝中爬行的百足般悄然伝播，像隠藏在梁上的毒蜘蛛般阴険地潜入人们的心中。
 这些谣言囲绕着为何法师的庵没有出现怪异。
>
#
>
# 谣言如常附加了各种尾鳍，最终帰结为瑶藏有名香。
>
#
>
# 香气本就被认为能净化心身，其薬效不仅如此，还能駆魔或引魔。
 悪魔学徒在画五芒星魔法阵进行召唤术时，香烟是不可或缺的，这既是対魔物的供奉，也是保护自身的结界。
 此外，大陆汉代武帝因思念已故妻子，焚焼反魂香，在香烟中见到了瑶的身影；西行法师隠居山中，因无法忍受孤独，试图用反魂香复活野晒的骨头作伴。
>
#
>
# 虽然列挙了些博物学的例证，但重点是香的霊験。香气虽不如利剣斩魔，也不如威容吓退魔物，但其芳香不可小颪，这些例证多少能证明这一点。
 此外，香有动物和植物来源之分……不过，还是回到以旅馆为舞台的故事槇―――
>
#
>
# 総之，琵琶法师住在水路旁，却未受黒色小人的侵害，是因为瑶秘藏了霊験顕著的名香，这样的谣言逐渐在人们口中伝开。
>
#
>
# 即便如此，起初也有人冷静地质疑，那个过着贫困生活、唯一的财物就是一把破旧濶臓的琵琶，甚至连食物都要从周囲的草丛中拔草充饥的女人，怎么会拥有如此稀有的东西。
 総之，那女人除了弾琵琶或者讲故事之外，既没有高深的智慧也没有见识，是个愚蠢的人，有人嘲笑瑶说，这样的人怎么会有珍贵的香料。
>
#
>
# 然而，当怪异的危害频繁到无法忽视的地歩时，困境使人们的判断変得模糊，他们的想法也随之改変，认为瑶可能拥有，甚至肯定拥有那种东西。不仅如此，他们还责备瑶，既然有这种駆魔的东西，为什么只让自己享受其恩惠。
>
#
>
# 即使只是确信瑶拥有那种不确定的东西也就罢了，但懐疑法师独占了它，这种疑心生暗鬼的想法有些不自然，虽然也有人対此表示懐疑，但大多数人还是随波逐流。
>
#
>
# ……然而，如果此时有研究口碑伝承的学者在场，鸟瞰并分析这些流言的流向，他会髪现流言的源头和人们忽略的某个事実。
>
#
>
# 如果仔细追溯法师藏有香料的流言，像追寻织物的绫线一样，最终会髪现源头在那个地下酒馆，找到那个用粗俗的言辞和手势讲述的男人。
 那个行为不端的醉汉，试图嘲笑和戯弄法师，激怒了筑宫。
 而且，人们还会髪现，和那些受害者住在同一条水路旁的房间里，还有一个从未见过黒色小人怪异的人。
 那个客人，就是那个失去记忆的年軽人――対，正是筑宫清修本人。
>
