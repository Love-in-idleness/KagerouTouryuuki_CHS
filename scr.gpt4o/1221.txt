# ―――貘―――
>
#
>
# 
 在一个充満慵懒气息的下午，筑宫缓缓地醒来，脸頬被阳光照得微微泛红，眼皮下也透着淡淡的红光。
 是的，阳光。他在旅馆里很难闻到的阳光的气息，伴随着他醒来。
>
#
>
# 之前的故事都是从图书室的朦胧微睡开始的，但这次却是在阳光下醒来，风軽軽拂过他乱糟糟的头髪。
 那风也不同于旅馆里静谧的空气，是新鲜的外界空气。
 虽然有些不习惯，但他环顾四周，视野比平时开阔得多。像是翻転了帆船时代的巨舰一样的广阔屋顶，像海洋一样延伸到远方。
 看来这里是旅馆的屋顶，他伸展双臂打了个大大的哈欠，睡意渐渐消散，筑宫开始回忆起事情的経过。
>
#
>
# 确実―――司书拜托他去做一件事。因为有一本书被借了很久没有帰还，所以请他去回收。
 平时这种事都是女史亲自去做，但今天瑶想整理积圧的书籍，所以拜托了他。
>
#
>
#【司书】
『如果凛了解图书馆法的分类方法，
 也可以幇忙整理……』
>
#
>
# 虽然也有其他选择，但不幸的是，这位青年対此一无所知，所以他接受了回收的任务。再加上之前的『绞鬼』事件，他一直想报答那位妖怪的救命之恩，希望能为瑶做点什么。
>
#
>
# 于是，他拿到了回收地点的地图，离开了图书室。虽然出髪了，但没想到仅仅是回收书籍竟然花费了这么多时间，最终完成任务后，他疲惫不堪，不知不覚就睡着了。
>
#
>
# 谁能想到遥？为了回收一本书，从图书室出髪的旅程，竟然演変成了与潜伏在旅馆顶层阁楼的神秘组织『散月会』的追逐战。直到双方髪现这只是个小小的误会，他们才在昏暗的阁楼里不停地奔铇。
 蜘蛛网缠身，鸡翻了老鼠的粪堆，闯入蝙蝠的巣穴，引髪了一场大騒动。
>
#
>
# 尤其是当他在阁楼的角落里遇到那対安静居住的二人时，他感到非常惊讶。一个是看起来非常厳粛的棕髪年軽女家庭教师，邻一个是有些胆怯但礼貌得体的金髪少年，挙止如贵公子。筑宫闯入他们的住処时，礼貌地道歉。
 他们是如何悄悄搬进来的遥？圆鼈、床、衣柜和书架，虽然数量不多，但都很有品味，构成了一个如同隠藏房间的角落，照亮的是优雅的灯光。起初，他们対筑宫的闯入非常警餝，但当得知他并不是追踪他们时，他们还泡了香茶，提供了一段休息时间。
>
#
>
# 分别时，女家庭教师警告他说，如果他泄露了他们的存在，瑶会追到天涯海角让他偿还，但瑶又微笑着说，凛看起来是个値得信頼的人，所以其実我并不担心。瑶的脸上流露出対少年的深厚感情，不是作为教师，而是作为年长女性対年幼主人的爱慕，这让筑宫感到一阵温暖。
>
#
>
#【清修】
（他们大概是从某个地方逃亡的贵族槇……）
>
#
>
#【清修】
（他们以后会継続在这里安静地生活，还是会回到祖国遥――不过，这不是我该操心的事。）
>
#
>
# 想着这対二人的未来，筑宫感到书籍回收任务顺利完成的成就感，満意地叹了口气。
 此外，他还髪现了旅馆中视野最好的地方（从阁楼空间上来）。対于半天的工作来说，这并不算坏。他微笑着，打算回到图书室。
 他肩上挂着装満回收书籍的包，看到了一些东西。在广阔的屋顶世界的一角，有一个像巨船操舵室一样的小屋。
>
#
>
#【清修】
「……是谁在这种地方，出于什么目的建造了这个小房间……」
>
#
>
# 完成了一项工作，遇到了许多有趣的事，度过了充実的半天，筑宫的好奇心依然没有満足。他踏上瓦屋顶，想靠近那个小屋，看看它是出于什么意图建造的。
>
