# ―――次日清晨―――
 一个人在房间里吃早餐，虽然味道応该和往常一样美味，但却感覚像是用假材料做成的，毫无滋味。
 不过，筑宫并不认为有啮个闲得无聊的仆人会故意捉弄他，这只是他的心情使然。
>
#
>
# “好主意是晨光帯来的”，这似乎是某个格言，但実际上，刚起床时血液循环不畅，思维并不霊活。筑宫首先想到的是去找渡船人，这并不是他自己突然想到的，而是昨晩令嬢示唆的。
 ……也许正因为一直想着这件事，他才没能品尝出早餐的味道。
>
#
>
# 毕竟，是那个渡船人把他帯到这里的。不论是暂时留在这里，还是马上离开，他都応该去见瑶，打好関系。
>
#
>
# 総之，筑宫上紧了银懐表的髪条，出门寻找渡船人的身影，但瑶的行踪不定，常在旅馆的各処渡水，问了仆人也不清楚，
>
#
>
#【仆人】
「鹡……今天没见到瑶遥」
>
#
>
# 于是，筑宫想瑶大概会在码头或伸向大河的桟桥上，便不再多想，径直走了过去。
>
#
>
# 徒労无功地错过了目标，连吹过水面的微风也顕得更加凄凉。然而，筑宫依旧耐心等待，倣佛在模倣一部老电影中的情节，悠闲地坐在水边，目光注视着随着缓慢节奏拍打岸边的波浪，不知过了多久，尽管没有划船，他的身体却大幅度地揺晃，険些头朝下栽进水里。
>
#
>
# 昨晩难以入睡的疲惫似乎在作祟，他愤然四処张望，担心刚才的笨拙姿态被人看到，但并没有人注意到他，渡船的船夫也不见踪影。
>
#
>
# 他一度想要放弃今天的计划，但又覚得正是因为这种薄弱的意志才会差点掉进水里，于是軽拍脸頬，重新振作精神，决定再去旅馆里找找看。
>
#
>
# 整个上午，他像觅食的水鸟一样忙碌地在各条水路间穿梭，旅馆的各个角落都能看到他寻找的身影，但最终他还是没能遇到渡船的船夫。
>
#
>
# 或许这也是命运的安排槇，他坐在水路边，脱下鞋袜，把疲惫的双脚浸入水中，叹了口气。
 虽然他自认为已経习惯了长时间行走，但今天却感到全身血液不畅，肌肉隠隠作痛。
 他试图寻找原因，突然脸红了。
>
#
>
# 原因顕而易见。
 昨晩，他过度使用了不常用的肌肉。
 他自问为何如此愚蠢，甚至感到难堪，昨晩他究竟和那位小姐度过了怎样的夜晩。
 他再次覚得今天见到渡船船夫的希望渺茫，但还是穿上鞋，継続寻找瑶。
>
#
>
# 或许他有些固执，但这样也好。
 晩上喝酒，出迷于女人，那么白天做了什么遥？回想起来，他只是放弃了寻找，等待天黒。与其这样，不如稍微坚持一下，継続四処寻找，这样至少还能対得起太阳。
 而且，这样让身体疲惫，至少今晩能好好睡一覚。
>
#
>
# 正因为他下定决心要找到天黒，所以当他决定从船坞开始寻找时，筑宫感到有些意外。
>
#
>
#【渡船船夫】
「𫚕，老爷……看起来凛气喘吁吁的尧」
>
#
>
#【渡船船夫】
「先润润喉龙，来一口如何？」
>
#
>
# ……究竟是什么时候错过的遥，渡船人已経划着小船靠近了码头，还愉快地向青年挥动他心爱的葫芦。
 看来他从白天就开始喝酒了，看到渡船人正在寻找他刚才自我警告的酒和女人的组合，筑宫露出了微妙的表情。
>
