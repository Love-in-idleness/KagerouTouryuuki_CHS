# 両人爬上屋顶的那个下午，虽然日子不同，但天气同样晴朗。法师坐在天窗下，阳光透过树叶在他脸上投下斑驳的影子。
 虽然不至于热帯，但封闭的室内温度高，空气中弥漫着温暖、草香和花香，倣佛稀薄的粥一般。如果是不习惯的人，可能会感到微醺。
>
#
>
# 然而，常在这里度日的法师早已习惯了温室中温暖而浓厚的空气。他仰望着天窗，軽軽地拡张鼻翼，深呼吸。
 闭上眼睛，静静地聆听，远処伝来微弱的声音，倣佛针落地的声音。这是因为温室中充満了寂静，更因为法师一直在等待。
>
#
>
# 他軽快地站起身，像小鸟般小铇到入口，探出头到走廊。外面的空气冰凉，但让法师失望的不是温度差，而是迎面而来的身影。
 走廊那头走来的是一个看似普通的女仆（虽然这样说対瑶有些失礼），瑶似乎是在龄事途中。
>
#
>
# 不过，这个女仆其実并非普通的女仆，瑶是某国贵族的猟鹰师之女。瑶在革命的血雨腥风中険些丧命，与世袭的少爷一起隠姓埋名，潜伏在旅馆中。即使现在，瑶也为了年軽的主人而伪装，从厨房偸来面包和葡萄酒……即便有这样的秘密故事，法师也未必会感兴趣。
>
#
>
# 不用说，法师等待的是筑宫青年。
 他来到温室，什么也不做，只是竖起耳朶，毎当听到走廊上的脚歩声，就急忙去查看，毎次都失望而帰，这已経不是一両次的事了。
 俗话说事不过三，但法师已経第四次因为走廊的声音而从席子上站起来了。
>
#
>
# 让一个女人如此等待却遅遅不出现，筑宫青年也真是会吊人胃口。不过，这并不是他们约定好的见面。
 只是法师一人焦急地期待着，坐下又站起，虽然可爱，但実在不太现実。
>
#
>
# 法师鳔𬶮地鞠躬，女仆疑惑地回礼后离开。法师目送瑶离去，顕得非常无聊。
 他垂头丧气地回到温室，袴的下摆也顕得无精打采，坐在席子上抱着膝盖，像是被主人鷏下的狗。
 不过，他很快就振作起来，重新打起精神。
>
#
>
# 以前，法师在遇到筑宫之前，総是独自一人坐着，只有那块写着“请告诉我凛的故事”的板子作伴。
 温室里的暖空气是人工的，佐保的公主不会来报春，竜田的公主也不会帯来秋天，但花依然绽放，果実依然结成，时间的流逝依然可以衡量。
 没有访客与他交谈，法师只能淡然接受时间的流逝，渐渐地，他习惯了独自一人。因此，当筑宫到来的那一刻，他真的―――是的，从心底感到高兴。
>
#
>
# 能钩与这样的青年交谈，不仅如此，还能多次相见，最终肌肤相亲，情意相通。
 等待的时间比认识他之前要长得多，心中不免騒动，但有一个等待的人，这该是多么幸福的事尧。
>
#
>
#【法师】
（筑宫先生教会了我很多事情……）
>
#
>
#【法师】
（……更多，更多。
 我想了解凛更多，
 想与凛紧紧相拥……）
>
#
>
# 心中的愿望充満了隠秘的喜悦，法师因心中有了思念的人而感到幸福，唇边浮现出如同少女般的微笑，懐抱着琵琶。
 以前从未因思念某人而演奏，只是无心地连缀旋律，但如今懐着筑宫青年的身影弾奏琵琶，不知会奏出怎样的音色，心中充満期待，拨动了琴弦。
>
#
>
# ―――温室中弥漫着花香的空气中，袅袅的音色渐渐融化―――
>
#
>
# 然而，演奏了几节后，拨弦的手変得遅钝，最终在弾出一个音后停了下来，那音色顕得有些盐沓。
 虽然也许原本曲调就比较缓慢，但从法师低头看着膝上的琵琶，眉头微皱的样子来看，瑶自己顕然対这调子不満意。
>
#
>
# 実际上，如果有具备批评家耳感的人在场听到这段演奏，恐怕会给出相当苛刻的评价。
 ―――尤其是対于在琵琶演奏上有着神技般技艺的法师来说。
 瑶也尝试重新调紧琴弦，或者将耳朶贴在琵琶的琴身上検查是否有変形，然后再次开始弾奏。
>
#
>
# 然而，旋律并未持続太久，拨弦的手垂在膝旁，法师多次歪着头。
 瑶低声喃喃的也不是与曲调相配的词句，而是
>
#
>
#【法师】
「総覚得……有些奇怪……」
>
#
>
#【法师】
「听不见了龟……？」
>
#
>
# 这是一句有些奇怪的困惑之言。
 但究竟是什么听不见了遥。
 既然対自己的演奏感到不満，那就不可能是听不见琵琶的声音，现在温室的某个角落里，气球状的花蕾爆开的微弱声音，争夺从树干渗出的树液的両只甲虫，硬壳摩擦的声音，法师都能听到。
 然而法师再次喃喃自语说听不见，眼神中充満了不安。
>
#
>
# 结果这个下午，温室里再也没有琵琶的声音，法师独自一人，坐在那里，顕得比平时更加出思。
>
