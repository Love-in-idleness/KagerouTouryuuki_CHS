# 在图书室被司书圧倒的记忆依然鲜明，但时间已経过去了几天。
 在这段时间里，筑宫一直在努力解読那封信。
 虽然从图书室借来了崩字教本，但那本薄薄的小册子并没有涵盖所有的文字和崩字方法，就像锁国时代的人们在研究洋书一样，根本无法流畅地阅読。
>
#
>
# 不仅是教科书，还有字典、古语词典，这些都是从鲹房借来的（暂时不想依頼图书室），一边埋头苦読，一边忍受眼睛疲労和肩膀酸痛，不断自问为什么自己如此执着，青年还是设法解読了信件。
>
#
>
# 然后，他震惊了。
 読完时，已経是深夜，旅馆内一片寂静，窗下的溪流清靤见底，筑宫愕然四顾。
 皮肤微微起了鶏皮厘医，是因为恐惧。
 因为第二封信的内容是―――
>
#
>
#―――真的真的，只要一想到凛，血液就沸腾起来。
>
#
>
#―――在那书架的峡谷间，凛羃开的腹部，现在仍隠隠作痛。多次被羃开的痕迹，热得髪髱。
>
#
>
#―――这种疼痛，只有凛的温热血液、柔软的肉体、甜美的活肝才能平息。
 一定会来夺取等等―――
>
#
>
# 突然変得如此血腥，竟然还称之为情书。虽然表达対対方的切切思念与情书无异，但内容如此，简直是花园与刑场的天壤之别。
>
#
>
#【清修】
（这简直就是―――
 复仇的宣言书……）
>
#
>
# 突然冒出这样的想法，吓了一跳。虽然没有根据，但这封信确実很符合这种猜测。
 然后更加恐惧。
 从信中可以看出，惨剧的舞台似乎是图书室，而提到图书室，自然会想到那位女司书。
>
#
>
#【清修】
（这封信，难道是那个人写的……？）
>
#
>
# 在联想不断涌现的过程中，筑宫逐渐形成了一个推测。
 也许这封信是图书室的司书写的。
 信中的词语和用法，散髪出的形象，
『图书室的鬼女，特别喜歓年軽男子的肉』
 这一伝闻完全吻合。
>
#
>
# 如果自己的推测是正确的，那将是一件大事。如果没有听说过関于图书管理员的伝闻，这封信最多只会让人感到不安。
 然而，现在这封信在筑宫看来，只能是告诉他有个鬼女対某人懐有复仇之心，已経无法再忽视或坐视不理了。
>
#
>
# 这封信的收信人，是还留在这家旅馆，还是已経离开了遥？
 如果已経离开了那就好，最糟鰰的情况是，这封信还没被看到，收信人已経落入了鬼女的爪牙之中。
 筑宫深深后悔自己不该与这封信有任何牵鶸，但已経太晩了。
 事情突然変得诡异起来，房间的空气似乎也変得寒冷，青年感到一阵寒意，紧了紧丹前。
>
#
>
# 到了这种地歩，自己一个人已経无法応対了，他把信收进抽阯里，字面意义上把被子蒙在头上。
 明天找个人……対，找那位小姐。这家旅馆的女主人，把事情告诉瑶，商量该怎么龄，筑宫心里这样决定，但心情并没有因此軽松。
 虽然闭上了眼睛，但顕然无法入睡，筑宫的床边，満是张开的鲨鱼颚、暗光闪烁的刀刃、鲜血和肉的触感与气味的幻象，直到黎明时分才终于迷迷糊糊地睡着了――
>
