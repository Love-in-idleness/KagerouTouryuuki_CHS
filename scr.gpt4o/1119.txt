# 接下来的几天，筑宫在陌生的床上度过了烦闷的时光。感覚好像有很多事情要思考，但実际上几乎没有。総之身体很疲惫，连站起来都覚得懒惰，更别说出门了。
>
#
>
# 在床上的期间，女仆照顾得很周到，所以没有不便，但自那天以来，小姐再也没有来过筑宫的房间。问女仆関于小姐的事，也得不到明确的答案，不知道瑶的消息，也无法见面。不能自由走动是一方面，像余烬一样熏的情欲也在折磨着他。
 没有机会和小姐谈话，从某种意义上来说是幸运的。但要向女仆请求“陪伴”，又覚得自己作为男人的卑劣部分被掲露出来，感到卑鄙和可怜。那么自慰……却有强烈的抵抗感，不知为何。也许这属于他失去记忆前的自我规范。総之，身体的不便和禁欲双重折磨着筑宫。
>
#
>
# 尽管如此，他还是勉强站了起来，至少在被関押的房间附近可以走动了。但这样一来，他注意到了一件事。女仆的目光総是从暗処注视着他。这简直像是被监视一样。実际上，这不就是在监视龟？
 于是筑宫的窘迫感日益加深。最终，即使出了房间，也只能去厕所。
 大概即便如此，女仆也会抱着尿瓶飞过来，所以他半哭着请求至少放过这点，才得到了允许。
>
#
>
# 事情髪展到这一歩，真是越来越不明白了。以前的小姐，応该会支持并幇助他恢复记忆。可现在却相反，像是把他软禁起来。由于只能待在房间里郁郁寡歓，筑宫的思绪日益向黒暗方向髪展，最终甚至懐疑小姐是否懐有某种悪意，把他困在这家旅馆。
 尽管如此，筑宫还是试图相信小姐。一定是有什么原因的。
>
#
>
# 确実，不加思索地完全信任某人是一种愚蠢的行为，但在没有掌握情况、信息不足的情况下，懐疑一切也是一种浅薄的表现。
 ……这是筑宫自我警戒的想法，充満了相当不错的伦理観，但他无意识中総是努力这样做。这是他的本性，还是失忆前教育的结果遥。
 総之，即使在被软禁的日子里，筑宫依然试图信任那位小姐。
>
#
>
# ……终于有一天，他听到了颠覆这种想法的话语。
>
#
>
# 那是某天下午，他去厕所的时候。在回房间的途中，有一个为女仆准备的伝声管，盖子开着，从那里伝来低语般的声音。在辨别出说什么之前，筑宫全身起了鶏皮厘医，后退了一歩。
>
#
>
# 从伝声管口飘来的，是那令人厌悪的气味，那种‘浊气’的气味。
 那么，那声音可能是与浊气有関的人，最糟鰰的是他们本人的声音。
 即使是危机感遅钝的筑宫也学会了，从伝声管前逃走，但他的脚歩停住了。
 因为他听到了低语中提到自己的名字和那位小姐的名字。伝声管中伝出的低出声音，大致在低语着这样的内容。
>
#
>
# 
―――旅馆守护者的家族，最后只剩下那位小姐。
>
#
>
# 
―――瑶是最后一个。如果瑶的血脉断绝了，这个旅馆会変成什么样子？
>
#
>
# 
―――需要一个伴侣。
>
#
>
# 
―――需要一个留下来，成为瑶的配偶，伝承血脉的男人。
>
#
>
# 
―――不，不仅仅是我们在担忧。
>
#
>
# 
―――那位小姐也応该明白这样的事情。
>
#
>
# 
―――所以，那个人―――
>
#
>
# 
―――打算让他成为伴侣―――
>
#
>
# 
 那些阴惨却又帯着几分哀切的低语，最后留下了筑宫的名字便戛然而止。
>
#
>
# 事后回想起来，那些通过伝声管的低语，似乎是故意让青年听到的。然而，当时的筑宫只是感到震惊，尽管如此，他还是装作若无其事地回到了房间。
>
#
>
# 青年盘腿坐在被褥上，思考着各种事情。确実，他听说过那位小姐是管理人家族的最后一人。然而，筑宫从未考虑过旅馆的未来会如何。毕竟，他只是一个暂时的客人，担忧旅馆的未来也无済于事。
 但是―――
 如果他们打算让自己成为这旅馆的主人，成为那位小姐的伴侣，那事情就完全不同了。筑宫突然感到一阵焦虑。
>
#
>
# 与此同时，之前不明白的部分，在新的视角下逐渐连贯起来。为什么那位小姐会如此厚待一个没有记忆、衣衫褴褛的自己？更不用说，为什么瑶会允许自己接触瑶的身体？为什么在自己与邻一个女人髪生関系后，瑶会如此愤怒？还有这几天的软禁状态。如果这种状态最终会解除，那还好。如果这种状态会一直持続下去遥？
>
#
>
# ―――希望凛成为我的伴侣―――
 当这样的提议出现时，自己是否还有选择的余地？
>
#
>
# ……如果有冷静的旁観者在场，或许会指出筑宫的推测缺乏依据，只是自我意识过剩的误解。然而，此时的他缺乏冷静的判断能力。几天的软禁生活和禁欲让他的头脳如同被热气熏蒸，这也是无可奈何的事。
>
#
>
# 筑宫想着必须逃脱，视线突然停留在房间的壁鞜上。
