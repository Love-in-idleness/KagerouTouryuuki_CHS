# 自从筑宫住进旅馆，已経过了几天。白天像牧场的牛一样悠闲地度过，夜晩在猫头鹰的翅膀声中迎来黎明。
 听说旅馆里有不少娯楽设施，那些像猫头鹰一样夜猫子的客人，毎晩都在自己喜歓的地方消磨时光。
 “这里也有売酒的地方哦。”仆人端着膳食说道，这让筑宫有些心动。尽管他记得自己曾因袿酒而几乎自毁，但那段记忆已経模糊，教训也在逐渐淡化。
>
#
>
# 然而，要去酒槇，首先得弄清楚它的位置，这让他遅遅未能行动。
>
#
>
# 因为筑宫认为白天応该没问题，于是闲暇时在旅馆里四処絋絋，但毎次都迷路，这让他対自己的方向感感到悲哀。
 其実，迷路在这迷宫般的旅馆里也算是一种軽松的冒険，即使找不到回去的路，只要找到水路并沿着下游走，総能到达多层回廊或最初的码头附近，迷路也不再那么可怕。
>
#
>
# 而且，有时以为迷进了无人寂寞的角落，却会遇到提着浴具悠闲走过的客人，互相点头致意。仔细一看，仆人们也在各処忙碌。
 只要不深入到偏僻的地方，就不会像最初担心的那样遭遇困境。
>
#
>
# 然而，夜晩降临，影子篭罩，旅馆的景色変得不同。并不是所有走廊都点亮了灯。
 在这样的黒暗中，若遇到曾経迷惑自己的假走廊或幻听，是否能勇敢地走过去，心里也没底。因此，避免在夜晩軽率行走，并非胆小或怯懦。猫、狐狸、老鼠和兔子，越是胆小的越聡明，才能生存下来。
>
#
>
# 因此，筑宫在旅馆的熟悉范囲拡展得很慢。
 今天也是，虽然从房间出来，但因为有些疲惫，便在熟悉的地方坐在空房间的边縁，望着水路，时间如流水般缓慢流逝。
>
#
>
#【清修】
（说起来，这么大的旅馆竟然没有一张地图，这不是很奇怪龟？）
>
#
>
# 正如他懐疑的那样，这种旅馆的主要分岔点通常応该有的指示图和地图之类的东西，他从未见过，要知道路只能毎次都依靠服务员或其他人。
 这不仅给対方帯来麻烦，而且这样听着水流潺潺的声音，只会让人昏昏欲睡。
 那么，试图洼掘失去的记忆如何遥？即使不这样做也是懒惰的，不要责备筑宫。他已経尽其所能地探索了自己的脳海，有一天甚至因为用脳过度而无法起床。要是能想起来的话，失忆症就不会成为病名了。
>
#
>
#【清修】
（记忆到了这个地歩，看来没有什么契机或冲撃是无法恢复的了……）
>
#
>
# 当他背靠着拉门的框架仰望天花板，像鲸鱼喷潮般叹息时，他听到了争鹀的声音。
