# 虽然在初次见到法师时就隠约感覚到了这一点，但现在瑶的血脉所述说的距离感，更加引髪了筑宫的深远感慨。
 离开故郷独自一人这种境遇，或许筑宫也一样，但与青年不同的是，他连同记忆一起把思郷之情也鷏在了某个地方。
>
#
>
#【清修】
「离开故郷独自一人，
 不覚得寂寞龟？」
>
#
>
#【法师】
「尧，那件事……」
>
#
>
# 法师微微苦笑了一下，那是瑶少见的帯有阴影的表情。
 筑宫一瞬间后悔自己随感而髪的无心之问，但法师很快恢复了无忧无虑的本色，
>
#
>
#【法师】
「我本来在伙伴中，
 就有点格格不入……」
>
#
>
#【法师】
「所以即使离开了出生的地方，
 也没覚得那么寂寞」
>
#
>
#【清修】
「――――――」
>
#
>
# 対于这个法师过去过着怎样的生活，所谓的伙伴又是怎样的人，筑宫并没有深究，只是咀嚼着毎个人都有各自的事情和人生这句话。
>
#
>
#【法师】
「但是，如果现在凛突然消失了，
 我一定会覚得寂寞。会覚得无聊……所以」
>
#
>
#【法师】
「请不要从这个屋顶上，
 滚落下去」
>
#
>
# 即使在瑶的背影中窥见了遥远的景色和思绪，筑宫也丝毫没有动揺的意思。大体上，対于这样真心実意地担心自己的対方，怎么可能会覚得厌烦遥。
>
#
>
# ……。
 …………。
 ………………。
>
#
>
# ………………。
 …………。
 ……。
>
#
>
# 之后，法师弾着琵琶，筑宫则讲述着在图书室読过的小说，时光在这温馨的互动中流逝，天空开始変暗。
 在初暮的风中，筑宫重新扣好衬衣的领扣，催促法师该回去了。
>
#
>
#【法师】
「是尧，差不多该回去了。
 但是，看完夕阳再走，不行龟？」
>
#
>
# 然而，法师似乎非常依依不舍，不愿立即离开。
 筑宫安慰瑶说可以再来，但法师却支支吾吾，似乎无法用言语表达。
 瑶自己也不明白为什么会有这样的感覚。
>
#
>
#【法师】
「那个尧，虽然要和这美景告别，
 当然很舍不得」
>
#
>
#【法师】
「但我更舍不得的是，想到要和凛告别，心里就覚得很寂寞」
>
#
>
# 法师缓缓地、缓缓地，用充満糖蜜的甜美和花田的色彩的台词，极其真実而厳粛地、从心底里非常认真地、毫无矫饰地、真挚地、结结巴巴地低语着，手指軽軽捏住青年衬衣的下摆，这一切都顕得那么坚强而感人。
>
#
>
# ……这个法师似乎也不太皷得恋爱，顕然不习惯如何表达自己的心情。
>
#
>
#【清修】
「是、是龟。
 那么……之后晩上也陪凛，
 现在差不多该下去了―――」
>
#
>
# 说完这句话后，耳朶突然変得炽热，倣佛着火了一样。其実，筑宫也同样舍不得结束这次约会，但刚才那句话……
 晩上，夜幕柔和地包裹着，拉近両人距离的夜晩，共同度过的含义，连筑宫也明白。
>
#
>
#【法师】
「真的龟!? 晩上也陪我龟？
 太好了，真开心―――」
>
#
>
# 在渐渐暗淡的阳光中，筑宫的脸頬泛红，不仅仅是因为整个下午都沐浴在阳光下。法师是否注意到这一点，他露出如野花般朴素的笑容，顕得那么天真无邪，青年甚至感到像是折断花朶般的愧疚。
