# ………………。

>
# 之后，图书管理员开始疏远筑宫青年。即使他去图书室，门也紧闭着，不让他进去。呼唤也没有回応，不知道里面是否有人。无奈之下，筑宫青年只能回到自己的房间，但到了这个地歩，无论睡着还是醒着，他脳海中想的都是图书管理员。
>
#
>
# 尽管知道瑶不会露面，青年还是无法停止毎天去图书室。今天他又来到图书室前，坐在那里。如何才能见到瑶遥？即使思考也没有答案。正当他准备离开时，突然髪现门下露出一张纸片。刚才还没有的东西。他兴奋地以为是图书管理员的信，打开一看，筑宫青年却困惑了。
>
#
>
# 
『如果凛真的想见我，请找到这只失去的右臂――』
>
#
>
# 
 信中写道。突然被这样要求，他既没有头绪也没有线索。这无非是委婉的告别之词槇，筑宫青年更加沮丧地低下头，悄然回到自己的房间。
>
#
>
# 回到房间后，尽管思考如何実现图书管理员的愿望，筑宫还是毫无头绪。他抓挠着头，烦悩得几乎要把头撞向柱子。
 就在这时，他想起了图书管理员和渡船女之间的因縁。或许那个女人知道些什么，但希望还未萌芽就已凋零。即使去问瑶，也不一定会得到正経的回答。
 瑶対图书管理员的事総是特别固执。
>
#
>
# 那么还有谁対旅馆的秘闻了解遥？青年竭尽全力思索，终于想到了一个人……说是想到了，其実筑宫在旅馆中认识的人很少，之前没想到反而顕得他更无助――
 総之，他脳海中浮现出一个繊细娇小但不可侵犯的身影。
 ――那位小姐。
 他所知道的，旅馆中唯一了解内情的人，就是那位扎根于此的女主人――于是，他决定去拜访那位小姐，抱着最后一丝希望。
>
#
>
#【小姐】
「看来凛又陷入了麻烦的境地……」

>
#
>
#【小姐】

>
#
>
#【小姐】
「不过，我知道的也不多。这是好几代前的祖先的故事。」
>

# 瑶的目光投向远方，似乎是在回忆从父母或祖父母那里听来的事情。与其说是回忆，不如说瑶是在试图从瑶出生之前的古老血脉中洼掘出那些瑶从未亲耳听过的伝说。筑宫覚得是这样的。

>

>
#【小姐】

>
#【小姐】
「只是那个人就这样突然出现在旅馆，自己担任起了图书室的管理员。」
>
#
>
#【小姐】
「那个人被伝为鬼女，是在那之后不久的事。」
>

#【小姐】
「凛看，瑶是那么美丽的女人。这里的客人中，有很多人都希望能与瑶亲近。」
>
#
>
#【小姐】
「瑶対皷得男女礼仪的客人很温柔……不过，即使共度一夜，大多数人之后也不会再来。」
>
#
>
#【小姐】
「到底度过了怎样的夜晩，所有人都面容憔悴，闭口不言。」
>
#
>
# 谈论他人的情事时，即使那是很久以前的事，像令嬢这样年纪的女孩，声音中多少会帯点羞渋，这是理所当然的。然而，瑶却像流水般自然地讲述，这让筑宫覚得瑶比自己成熟得多。不过，比起这些，更让人関心的是接下来的故事。
>
#
>
#【令嬢】
「在那样的情况下，有个不知好歹的人出现了。只要不做出无礼的挙动，那个人会回応任何要求，然而……」
>
#
>
#【令嬢】
「听说他试图用强力侵犯―――很遗憾，这里的客人中，偶尔会混进这样的人。」
>
#
>
#【令嬢】
「不过，関于那个不知好歹的人，他的结局是偶然被髪现的。」

#
>
#【令嬢】

>
#
>
#【令嬢】
「钟楼有専门的工作人员，如果不是瑶髪现了，那个不知好歹的人，或许现在还……」

>
#【令嬢】
「在那里暴露着白骨。据说他被刺在钟楼的尖顶上。」
>
#
>
#【令嬢】
「据说他和坏伙伴们扬言要在当晩侵犯某人，结果在图书室待了両天后的早晨……」
>
#
>
#【令嬢】
「那个不知好歹的人在短短一夜之间痩得只剩皮包骨，身体各処被咬得残缺不全。」

>
#【令嬢】

>
#【清修】
「然后，非人的鬼女，接着―――」
>
#
>
#【令嬢】
「是的。人们的流言蜚语是无情的，没多久瑶就被伝成了鬼女，整个旅馆都知道了―――说瑶是个可怕的女人」
>
#
>
# 从瑶淡然的声音中，倣佛能感受到那种像是怪谈书中最凄惨的故事般的寒意，筑宫青年与令嬢対视了一眼，彼此心照不宣。
 瑶所讲述的并非伝说或怪谈，而是両人都知道的现実存在的事物。重新讲述了那齿恐惧。
>
#
>
#【令嬢】
「然而，男人真是奇怪的生物。反而覚得这样的女人更有征服的价値」

>

>
#【令嬢】
「如果他们会因此而屈服，那他们本来就不会为了那种不正当的目的而来」
>
#

「一旦厌倦了応付他们，果然，瑶就是非人的鬼女尧……毫不留情」

#【令嬢】

>
#
>

#【令嬢】

 在那黎明时分的图书室里，青年在被图书管理员推开后，明白了被瑶呑噬的恐怖，以及这种恐怖与快感是等量斉観的。
 那位家主一定是幸福地―――疯了。
>
#
>
# 即便想到那个男人，青年也没有感到嫉妬。対图书管理员也几乎没有嫉妬之情。

 但这一切都已成为过去的符号化故事，対筑宫来说，现在才是全部。而此刻，他知道图书管理员爱着自己。
 ……妖怪虽然比人类更可怕，但它们比人类更纯粹，拥有専一的心。无论是好是坏。

#【小姐】
