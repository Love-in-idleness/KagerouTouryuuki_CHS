# ……他用高大的肩膀顶开壁鞜天花板上从未被人注意过的木板，用肘部当作冰苔爬了上去。対现在的筑宫来说，这就像在挑战西藏的悬崖一样艰难。他満身灰尘，气喘吁吁，终于爬了上去。然而，在阁楼的昏暗中，筑宫感到茫然失措。这家旅馆総是展现出各种荒诞的规模，阁楼也不例外，与通常想象中的阁楼相去甚远，呈现出一个奇异的空间。
>
#
>
# 大人可以悠然自得地站着走动，天花板到屋顶的高度也很高。裸露的柱子像古代树木的化石一样粗壮坚固，雑乱无章地到処耸立。看起来这是一栋経过多次拡建的建筑，地面的高度也不一致，有些地方似乎曾経被用作储物间，而有些地方则明顕留有最近有人起居的痕迹。
 说起来，在酒馆里听到过一个无稽之谈，说是有一个不明身齿的社区以屋顶为据点，当时听到时只当是醉汉的胡言乱语，但现在亲眼所见，覚得这伝言也未必毫无根据。甚至有伝言说，连那位幇佣也有専门适応这个屋顶空间的类型。
>
#
>
# 无论如何，虽然从被软禁的房间里逃出来了，但并没有明确的目的。
 想着随便找块合适的板子拆下来，顺着下去就行了，但往下看的时候，正好看到幇佣在走廊里来回走动，骭紧把头缩了回来。
 虽然不确定瑶们是否已経通报了自己的情况，但冒険并不是明智之挙。
>
#
>
# 无奈之下，只能在天花板上哄哄作响地走来走去，像个屋顶上的散歩者。虽然这个词帯有偸窥的猟奇色彩，但现在的青年已経疲惫不堪，困惑不已。
 幸好，虽然是屋顶，但并不是完全的黒暗。天花板的缝隙里漏下来的灯光，屋顶的通风窗透进来的光线，甚至有些地方屋顶破了个大洞，光线透了进来。
>
#
>
# 果然，这么巨大的建筑，要做到完美的修缮是很困难的。
 不知为何，脳海中浮现出被遗弃的帆船时代的巨舰，露出竜骨的景象。就在这时，鼻尖掠过一物，掉在了脚下。虽然吓了一跳，以为是住在屋顶的蝙蝠或蛾子之类的东西，但其実只是一个可爱的纸飞机。
>
#
>
# ――纸飞机？筑宫歪了歪头。为什么会有人特意在屋顶玩纸飞机遥？这种不合时宜的行为反而顕得诡异。重新环顾四周，屋顶上并没有其他人的气息。就在这时，又一个纸飞机从之前看到的天花板破洞里飞了进来，在光线中顕得格外鲜明。
>
#
>
# 看来，有人在屋顶上放飞纸飞机。
 筑宫看着那纸飞机，原本只想着回到楼下，但突然想到，干脆爬到屋顶上，从那里找到邻一条逃生路也是一个龄法。
>
