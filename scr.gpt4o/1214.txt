# 自从在图书室看到慢速玻璃后的几天里，心情跌到了谷底，这対青年来说是前所未有的。
 虽然他的性格并不是那种极端的楽観主义者，但也不是极端的悲観主义者或有毁灭倾向的人。
>
#
>
# 他也有普通人那样的楽観和忧虑。尽管失去了记忆，対未来感到不安，但身体健康强壮，年軽的他并没有陷入绝望。
 然而，这几天情况完全不同。完全不行。
 不知为何，他确信自己是个无用的人，活下去也不会有任何好事，前途只会有黒暗的命运在等待。
>
#
>
#【清修】
（――没有任何理由，为什么我会这么沮丧？）
>
#
>
# 他披着被子盘腿而坐，孤独地思考着。如果别人看到现在的筑宫，一定会覚得他非常落魄。自从从图书室回来后，他失去了走动的力气，几乎不吃饭，不洗澡，也不刮胡子，头髪乱糟糟，身体油腻，胡子在嘴边像胡椒塩一样，看起来非常镴𦈐。尽管女仆一开始还関心他，照顾他，但最终也放弃了，减少了去房间的次数，从昨天开始，只是按照固定的方式整理床舗和送饭，不再说话。也许是害怕青年的绝望会伝染，尽量减少在同一个房间的时间。这是完全有可能的。
>
#
>
#【清修】
「这可不妙……」
>
#
>
# 这样下去，他会一直困在房间里。即使是假装的活力也好，或者是暂时的消遣，他知道自己需要这些。然而，他不皷什么娯楽，也从未渉足赌博，至于女人，除了图书室的管理员，他也不认识其他人（失去记忆前的事不清楚）。
>
#
>
# 即使想出迷于肉体，瑶也太危険了。尽管瑶在图书室工作，但本质上是个鬼女，不仅不能消遣，还可能失去很多重要的东西，甚至可能真的溺死。更重要的是，无论対方是谁，为了排解郁闷而髪生関系，这违背了青年的道徳観。
 ……至于这种道徳観是天生的，还是被厳格教导的，他还不清楚。
>
#
>
# 総之，剩下的只有酒了，但在这种精神状态下喝酒是危険的，只会让心情更糟。
 从他在这家旅馆的日子开始，就是因为思虑过度，试图借酒消愁而失控。
 尽管知道这一点，但他不知道其他的依靠方法。
 如果喝到失去意识，至少不用担心失眠。
 実际上，筑宫从前天开始几乎没怎么睡，感覚自己有失眠症的倾向。
>
