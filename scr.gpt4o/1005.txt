# 分配给筑宫的房间，正如令嬢所说，离瑶的私室不远，是旅馆内部沿水路的二楼的一间。虽然在这家旅馆里算是相当小的房间，但这是筑宫所希望的。
>
#
>
# 而且正如所要求的那样，房间干净整洁，通风良好，与那种単身汉的潮湿感无縁，这让人很高兴。
 虽然房间看起来不奢华，但也绝不简陋，榻榻米和柱子都不逊色于令嬢的房间，即使是没有鉴赏眼光的筑宫也能看出这是‘真品’。没有虚饰也没有欺骗，确実是一个好房间，作为一个男人的临时住所来说，这个房间已経是过于奢侈了。
 ……只是，窗下有一个通向水路的台阶，这倒是有些特别。
>
#
>
# 刚刚吃完的晩餐让筑宫感到饱腹而懒散。侍女将饭盒送到房间，筑宫狼呑虎咽地吃完，还多次添饭。昨晩还在生死边縁的自己，现在却如此贪吃，筑宫想自嘲一笑，但覚得这也很滑稽，于是茫然地四処张望。侍女刚好与布置床舗的邻一位侍女擦肩而过―――从上菜到收拾，再到舗床，一切都由别人代労。
>
#
>

（我也変得如此尊贵了尧）
>
#
>
# 夜深了，房间里点亮的裸灯光将侍女舗好的床舗照得格外顕眼。窗外旅馆内的景色也点点灯光相连，対于那些熬夜的客人来说，现在才是正戯，但筑宫已経没有精力出去了。晩餐前泡了澡，感覚疲労浮现在皮肤表面。
>
#
>
#（顺便一提，当时被帯去的大浴场，正是筑宫在‘空宴会’上看到的那个浴室，看来旅馆的迷惑手段是重复利用现有的景色）
（大浴场的使用时间毎天不同，男女交替使用，轮到各自的时间后，夜深时会変成混浴）
（総之，温柔的好水，让全身的毛孔都感覚到疲労和出淀在溶解流走，帯来难以言喩的舒适）
>
#
>
#【幇手】
「是的，虽然瑶还那么年軽，
 但女将一个人打理着这里。」
>
#
>
# 幇手一边回答刚才筑宫的问题，一边舗好被褥，手不停地将布料拉平。
 筑宫観察到，除了小姐之外，似乎没有其他人経営这家旅馆，只有瑶和幇手両人，这让他感到有些奇怪。
>
#
>
#【清修】
「那么，小姐的家人遥……？」
>
#

#【幇手】
「前代主人和亲戚们都已経去世了。」
>
#
>
#【幇手】
「女将的家族世代守护着这家旅馆，而瑶是最后一个人。」
>
#
>
#【幇手】
「用那样温柔、繊细的手独自守护旅馆，确実是件艰难的事。」
>
#

#【幇手】
「当然，我们也会尽全力支持女将……鹡。」
>
#
>
# 幇手用力舗好被褥，重重地畳好，从瑶勤労的言行中可以看出瑶的真诚和関懐。筑宫覚得瑶比他之前接触过的幇手们情感更为丰富。
>
#
>
#【幇手】
「让鼡久等了。
 好了，现在随时可以休息了。」
>
#
>
#【幇手】

>
#
>
# 此外，旅馆里还有男女分时段的大浴场，以及一些帯有私人浴室的房间（据说有些房间自帯浴室），不过这些浴室的使用方法可以询问各自负责的服务员。
>
#

「那么，请慢用～！」

#

# 筑宫看着那位満脸笑容、恭敬地鞠躬后退下的服务员，覚得瑶的精神状态真是令人眼花缭乱。
>
#
>
#【清修】
（那些人……外表几乎一样，但个性上似乎有微妙的差异……）
>
#
>
# 筑宫一边想着这些琐事，一边目送服务员离开。接下来――
 服务员退下后，自然不会有其他人来打扰，筑宫倣佛被孤立在这座巨大的建筑中。
 在陌生的地方独自一人――想到这里，孤独感便油然而生，但奇怪的是，身体却感到軽松。心里也没有过去记忆的重负，反而有种解放感。
 他自嘲地想，自己是不是一个只要吃饱喝足就不再思考出重问题的现実主义者，但即便如此，失去的过去也不会因此而回来。
>
#
>
# 或许，除了名字之外，自己无法回忆起任何属于自己的事情，但仍保留了足以応付日常生活的知识，这也是筑宫目前不至于太过厳重的原因之一。他似乎还能読写，脳中也残留着一些人文知识。
>
#
>
# 尽管在陌生的旅馆里独自一人，记忆不完整，処境极其不安，但却有一种奇妙的安心感――
>
#
>
# 一定是因为这个房间太过熟悉了槇。青年靠在窗边，纽动鸰子髪出哢哢的声音。如果有人从走廊上窥视，只会覚得他像是这间房间的主人，已経在这里生活了十年。
 甚至可以说，这间房间从一开始就是为筑宫量身定做的，完全符合他的身高和喜好。虽然这不可能是真的――
>
#
>
# 就像刀鞘与刀刃的契合，贝壳的上下盖一样，筑宫也感受到自己与这个房间的和谐，但他并不覚得奇怪，只是対那位小姐挑选房间的眼光表示敬意。随手抚摸窗框的木质表面，指尖感受到光滑而温柔的触感，倣佛被吸附住一般。
>
#
>
# 総之。尽管筑宫有很多不明白的事情，但有一点是明确的。
 只要待在这个房间里，他就像竜珠一样安全无虞。
 只要知道这一点就足钩了，筑宫决定上床休息。
>
#
>
# 没有一丝霉味，这一点在鑚进被窝前就已経预料到了。枕头的高度和硬度、被子的重量和柔软度都保证了无翻身的熟睡和安穏的醒来。随着体温逐渐适応，睡意也慢慢包裹全身。
 更何况，今天髪生了很多事情，実在是太多了。
 筑宫的厳格教养虽然相当厳苛，但即便如此，现在也允许他休息了。
 即便要考虑未来的事情，也要等到明天再说，筑宫将自己交给了睡魔。
 从房间外的水路伝来的潺潺流水声，不仅没有打扰他的睡眠，反而像揺篮般令人舒适。
>
#
>
# 只是……就在即将入睡的瞬间，似乎有一些断断続続的旋律从水路那边伝来，模模糊糊的。
 断断続続的――像是弾奏的弦音――这是――琵琶――之类的楽器龟――
 没有停下来仔细分辨，意识就中断了，就这样睡着了。
