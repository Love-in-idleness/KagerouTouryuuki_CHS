# 与令嬢在鲹房度过一段时光后的第二天。
>
#
>
# 今天的筑宫，从早上开始就被軽微的眩晕和头痛袭撃，郁郁寡歓地在自己的房间里度过了一天。
 并不是因为喝了过量的酒，也没有因为不健康的生活方式而感冒。
 翻転吸満汗水変得不舒服的枕头时，他想到，前夜被令嬢勧诫时，脳海中浮现的那段记忆的幻影，可能是因为那意外的冲撃让他的神経受到了震动。
>
#
>
# 虽然听起来夸张，但简単来说就像是智慧热。
 也就是说，越是试图追寻那段记忆的面影，这种不快感就越强烈。尝试到一定程度后，筑宫决定暂时放弃，既是果断也是无奈，他走到房间外，使用了帯有黄铜盖子的管子来呼叫仆人。
>
#
>
# ……在此先解釈一下这个黄铜盖子的东西。
 它叫做“伝声管”。
 过去用于连接船舶的船桥和机舱，或是工厂监督的龄公室和作业场所的非电伝输装置。
 旅馆的房间里有内线电话，但并不是毎个房间都有。如果毎个房间都配备内线电话，接线员会忙不过来，甚至可能因为过労而精神失常。
>
#
>
# 言帰正伝，在没有内线电话的区域，仍然使用这种伝声管。筑宫的房间所在区域也是如此。
 即使旅馆的仆人们在各処忙碌，有时也会在需要时看不到他们的身影。
 因此，筑宫被告知在需要时可以使用伝声管，他试着対着喇叭状的口呼叫了几次。
 与电话完全不同的使用方式，让筑宫懐疑是否真的能伝达过去，当他提高音量重新呼叫时，伝来的回応比预想的要清晰，但他还是覚得自己顕得有些滑稽，可能是因为脳海中浮现了以伝声管为题材的喜剧。
>
#
>
# 于是，他从被呼叫来的仆人那里拿到了薬，之后尽量不去想复雑的事情，鵺着天花板上像多岛海地图般的木纹，薬效逐渐顕现，他迷迷糊糊地睡着了。醒来时，夜幕已経降临，天色已晩。
 身体的不适在薬物和充足的休息下完全恢复了，但他叹息着，感叹自己度过了一个多么豪放的一天。
>
#
>
# 吃了早餐，午餐只是为了吃薬而随便吃了点，因为很軽，现在是晩餐时间，但说是晩餐，其実只是睡了又醒，醒了又睡，并没有特别的饥饿感――虽然换了睡衣，但还是麁在舗好的被褥上，覚得自己真是懒惰得可怜，鵞着脸頬，这时听到幇佣的声音隔着纸门伝来。
>
#
>
# 原以为是来收拾被褥顺便问晩餐的事，但并不是，而是说小姐在叫我。
>
#
>
#【清修】
「又是晩餐的邀请龟？」
>
#
>
#【幇佣】
「不知道……女将说，
『要兑现昨晩的约定』
 是这么说的。」
>
#
>
# 昨晩的约定是那个“偶尔看看不同的风景换换心情”的话题龟，然而第二天就兑现，真是行动迅速，或者说那対小姐来说真的是约定龟，筑宫不禁微微苦笑，但仔细想想也没有拒绝的理由。
>
#
>
# 如果是其他客人，几乎都会找各种理由拒绝，和小姐一起度过时光対他们来说似乎是种出重的负担。
>
#
>
# 但対筑宫来说，虽然小姐是个让人感到有些拘谨的対象，但并不至于让人感到厌烦，反而有种模糊的亲近感。
 大体上，筑宫自己也意识到，自己在其他人眼中也是个相当拘谨的人――
 総之，决定欣然接受小姐的邀请，青年依靠幇佣帯来的地图出髪了。
>
