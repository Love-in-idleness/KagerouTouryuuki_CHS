#【青年】
「咦……？船坞……哪个是船坞？」
>
# 难怪难怪，难怪他声音有些发白。因为『客栈』的船坞，并非寻常所见那般，只有一根板桥从河岸伸出的简陋景象。
>
# 它更像一个巨大穹顶之内，或是一处供疲惫船只休憩的船坞。而且规模之大，适合远洋巨型货轮，而非区区小舟。
>
#【渡者】
「哪个是？你说得真怪。这里整个都是船坞呀。」
>
#【青年】
「是吗……」
>
# 人类身处过于宽广的空间时，反而会不知所措。
>
# 如同失去外壳的寄居蟹，若没有东西划分出自己的立足之地，便会感到不安。
>
# 青年怀念起船舱的狭窄，曾考虑要不要躲回去，但这念头也只是转瞬即逝。
>
# 当他用眺望大河上『客栈』时的方式调整目光焦点后，这空旷得有些浪费的船坞，却也流露出几分生活气息，几许人情味。
>
# 人类的营生，无论如何，总是带着些许俗气，若以鉴赏澄澈星空的眼光去看，难免会觉得刺眼。
>
# 例如，瞧那边，青年凝神望去，在沉入水面的阶梯旁，有个女子正浸洗抹布。
>
# 再转回视线，有女子在围拢船坞的房间窗户上晾晒沾着污渍的被褥，又有的在走廊角落里兴高采烈地聊天——这群偷懒的家伙，周围的人可都在忙碌呢。
>
# 虽然如此描绘，显得粗鲁又邋遢，但对于一直被迫以巨人视角看待大河和『客栈』的青年而言，这终于让他想起了人类的尺度生活，重拾了人的感觉。
>
# 这也归因于，周围处处是木造结构，尽管可见部分石灰墙壁和石砌结构，但整体都是由被手摸得光滑的木材搭建而成。
>
# 它与钢筋水泥建筑本质上所具有的，那种与生物格格不入的冰冷感截然相反。
>
# 青年此刻首次呼吸着『客栈』的空气，他深吸一口，肺中充满了那种感慨，那种他将在此度过漫长时光，时而遗忘，时而再次意识到的感觉。
>
# 
 ——旅愁——之类的， 
>
# 
 ——若要重复言说， 
>
# 
 ——亦是乡愁——吧。 
>
# ——那便是——
>
# ——这种被如此命名的，带着古老、哀伤又怀念的回响的词语，在心之水面上层层叠起波纹的感慨。
>
